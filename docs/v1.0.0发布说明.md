# GIS TOOL v1.0.0 发布说明

> 适用版本：`v1.0.0`
> 适用平台：Windows
> 产品定位：插件式 GIS / 遥感算法工作台

---

## 1. 版本概览

`v1.0.0` 的目标不是扩展产品边界，而是将当前工作区收口为一个更稳定、可验证、可交付的 Windows 算法工作台版本。

本版本继续保持以下边界：

- 仅支持 Windows
- 提供 CLI 与 GUI 双入口
- 采用全局 `vcpkg` 依赖模式
- 不包含地图展示平台能力

---

## 2. 本次发布的重点变化

### 2.1 GUI 主链补强

- 新增结果预览页，可在 GUI 内直接查看部分结果
- 增加工作流页面，并纳入 GUI 主流程
- 补强进度对话框与任务执行链路
- 优化首次运行引导与主界面文案一致性

### 2.2 可验证性增强

- 将预览页与工作流页面纳入 GUI 测试构建
- 补充裁切与匹配功能的 GUI 离屏回归测试
- 保留 Debug / Release 两套构建与测试入口
- 强化发布前回归路径，便于后续固定验收基线

### 2.3 结果表达与处理链完善

- 增加处理元数据写入能力
- 补充分块处理、日志、性能监控相关基础设施
- 统一部分 GUI、插件、构建与文档中的中文提示信息

### 2.4 交付与发布能力补齐

- 新增 Windows Release 的 NSIS 安装脚本
- 调整构建与发布相关文档
- 更新架构文档、用户手册与 README 的版本口径

---

## 3. 当前确认已具备的能力

截至本次收口，当前工作区已经具备或已接入以下能力：

- 结果预览
- 处理元数据
- 工作流页面与基础工作流能力
- 分块处理基础设施
- 日志与性能监控基础设施
- 首次运行引导
- 自动重试
- CI 缓存配置
- Release 全量测试配置
- NSIS 安装脚本

---

## 4. 验证口径

本轮文档与历史整理过程中，仓库内已明确记录并对齐了以下验证口径：

- `gis_tests` 可构建
- Debug 下核心测试可执行
- GUI 支持离屏自检
- GUI 关键流程具备离屏回归入口
- Release 侧保留真实数据专项回归目标

发布前仍应按项目文档执行完整验收命令，而不是仅以局部通过代替最终发布验收。

---

## 5. 不包含的范围

本版本不包含以下方向：

- 地图画布 / 地图展示平台
- Linux / macOS 适配
- `vcpkg manifest` 迁移
- 以扩张功能面为目的的大规模新增算法
- 脱离当前架构边界的大重构

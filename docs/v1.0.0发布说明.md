# GIS TOOL v1.0.0 发布说明

> 适用版本：`v1.0.0`
> 适用平台：Windows
> 产品定位：插件式 GIS / 遥感算法工作台

---

## 1. 版本概览

`v1.0.0` 的目标不是扩展产品边界，而是将当前工作区收口为一个更稳定、可验证、可交付的 Windows 算法工作台版本。

本版本保持以下边界：
- 仅支持 Windows。
- 提供 CLI 与 GUI 双入口。
- 使用仓库锁定的 `vcpkg manifest` 依赖模式。
- 不包含地图展示平台能力。

---

## 2. 本次发布的重点变化

### 2.1 GUI 主链补强
- 新增结果预览页，可在 GUI 中直接查看部分处理结果。
- 增加工作流页面，并纳入 GUI 主流程。
- 补强进度对话框、任务执行链路与首轮引导体验。

### 2.2 可验证性增强
- 保留 Debug / Release 两套构建与测试入口。
- 增加 GUI 离屏自检与关键流程离屏回归入口。
- 在发布流水线中加入安装态 smoke test，直接验证 `gis-cli.exe` 与 `gis-gui.exe`。

### 2.3 交付能力补齐
- 新增 Windows Release 的 NSIS 安装脚本。
- Windows CI 现已自动产出 `gis-tool-win64.zip` 与 `gis-toolkit-1.0.0-win64-setup.exe`。
- `vcpkg` 依赖切换为仓库内 manifest 管理，并补齐 `builtin-baseline` 锁定。
- 对依赖下载与配置步骤增加缓存和重试，减少构建波动。

---

## 3. 当前已具备的能力

截至当前仓库状态，以下能力已经具备或已接入：
- 结果预览。
- 处理元数据写入。
- 工作流页面与基础工作流能力。
- 分块处理、日志与性能监控基础设施。
- GUI 离屏自检。
- Release 安装产物打包与上传。
- 安装态 CLI / GUI smoke test。

---

## 4. 验证口径

当前版本建议按以下口径进行发布前验收：
- `ctest --test-dir build/debug -C Debug --output-on-failure`
- `ctest --test-dir build/release -C Release --output-on-failure`
- `cmake --install build/release --config Release`
- `install/bin/gis-cli.exe --list`
- `install/bin/gis-cli.exe vector buffer --input tests/data/gui_vector_projected_input.geojson --distance 10 --output install-smoke-buffer.geojson`
- `install/bin/gis-gui.exe -platform offscreen --self-test`
- NSIS 安装包构建与 artifact 上传

发布前仍应以完整验收命令与 CI 结果为准，而不是只看局部模块是否通过。

---

## 5. 不包含的范围

本版本不包含以下方向：
- 地图画布 / 地图展示平台
- Linux / macOS 适配
- 脱离当前架构边界的大规模重构
- 以扩展功能面为目的的额外算法铺设

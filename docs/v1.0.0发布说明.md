# GIS TOOL v1.0.0 发布说明

> 适用版本：`v1.0.0`
> 适用平台：Windows
> 产品定位：插件式 GIS / 遥感算法工作台

---

## 1. 版本概览

`v1.0.0` 的目标不是扩展产品边界，而是将当前工作区收口为一个更稳定、可验证、可交付的 Windows 算法工作台版本。

本版本保持以下边界：
- 仅支持 Windows。
- 提供 CLI 与 GUI 双入口。
- 使用全局 vcpkg + 仓库 `vcpkg.json` 依赖清单。
- 不包含地图展示平台能力。

---

## 2. 本次发布的重点变化

### 2.1 GUI 主链补强
- 新增结果预览页，可在 GUI 中直接查看部分处理结果。
- 增加工作流页面，并纳入 GUI 主流程。
- 补强进度对话框、任务执行链路与首轮引导体验。

### 2.2 可验证性增强
- 保留 Debug / Release 两套构建与测试入口。
- 增加 GUI 离屏自检与关键流程离屏回归入口。
- 在发布流水线中加入安装态 smoke test，直接验证 `gis-cli.exe` 与 `gis-gui.exe`。

### 2.3 交付能力补齐
- 新增 Windows Release 的 NSIS 安装脚本。
- Windows CI 现已自动产出 `gis-tool-win64.zip` 与 `gis-toolkit-1.0.0-win64-setup.exe`。
- `vcpkg` 依赖通过仓库内 `vcpkg.json` 声明并预装到全局 vcpkg，CMake 使用全局模式（`VCPKG_MANIFEST_MODE OFF`），并补齐 `builtin-baseline` 锁定。
- 对依赖下载与配置步骤增加缓存和重试，减少构建波动。

---

## 3. 当前已具备的能力

截至当前仓库状态，以下能力已经具备或已接入：

**正式能力**
- 结果预览
- 处理元数据写入
- GUI 任务中心日志（SQLite 持久化，通过 `ProgressReporter` 记录）
- 分块处理
- GUI 离屏自检
- Release 安装产物打包与上传
- 安装态 CLI / GUI smoke test

**增强能力（可用，承诺有限）**
- 工作流页面与预设工作流：GUI 可执行内置预设流程，暂不支持自定义参数配置（见 §7 已知限制）

**基础设施（已实现，尚未接入主执行链）**
- 核心 `Logger`：代码已实现，当前未接入插件/GUI 主链
- `PerformanceMonitor`：代码已实现，当前未产生运行时性能记录

## 7. 已知限制

- 仅支持 Windows 10+ x64 平台
- 单个栅格文件处理上限为 50000×50000 像素
- 工作流功能为初始版本，暂不支持自定义参数配置
- 核心 `Logger` / `PerformanceMonitor` 已实现但未接入主执行链；当前日志以 GUI 任务中心为准
- classification 和 georef 插件版本为 0.1.0，可能存在功能不完善
- 不包含地图展示/浏览功能
- 不支持点云数据处理
- 无国际化支持（仅中文界面）
- 无键盘快捷键

## 8. 系统需求

- 操作系统：Windows 10 64位或更高版本
- 处理器：x64 架构
- 内存：建议 8GB 以上（处理大影像建议 16GB+）
- 磁盘空间：安装约 500MB

## 2. 目标与全局验收口径

1. **无静默错误结果**：任何参数错误、表达式非法、GDAL/算法失败必须走 `Result::fail` 或非 0 退出码，禁止"成功 + 错误数据"；
2. **用户数据不可被静默破坏**：输出==输入必须有守卫；预设/历史/源文件不得被静默覆盖或删除；
3. **算法口径对齐行业标准**（批次 B）；
4. **崩溃安全**：所有跨线程执行路径有异常兜底与生命周期收口；
5. **可编译可验证**：HEAD 干净构建 + 全量 ctest 绿 + 每 action ≥1 数值金标用例 + 测试数据三态（CRS/NoData/符号量级/类型）齐备 + 无"跳过即通过"；
6. **GUI 与 CLI 契约一致**：同一 action 的必填集合与默认值跨入口一致；
7. 交付合规：干净机器可运行（运行库）、许可文本随包、无用户可见乱码。

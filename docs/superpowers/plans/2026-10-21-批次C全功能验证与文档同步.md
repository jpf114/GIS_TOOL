> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 126 个动作在真实数据（不足者用合成夹具）上全部验证到关系级、72 个 PENDING 全部晋升 GOLD；交付包"拿走即用"；125+ 篇文档与二进制逐篇机械同步；最后合并 master。

**Architecture:** 复用现有三条 `real_*_regression` 脚本结构（quick/full、数据无关判据）扩到全覆盖；新增 `--help` 导出器 + 文档核对器（ctest 化）；安装侧补 VC++ 运行库与裸环境 smoke。GUI 只保"能起 + 离屏用例不回退"，深化验证延后。

**Tech Stack:** C++17 / MSVC / CMake presets / GoogleTest / PowerShell 5.1（回归脚本）/ python（矩阵与核对器，本机用 `python` 不是 `python3`）。

**Spec:** 本文 + `docs/RELEASE.md`（收尾二/三轮）+ `docs/算法说明/文档漂移清单.md`（D1~D5）。
工单文本不是判据真源：**参数/行为的真源永远是当前二进制的 `--list/--help` 与 `paramSpecs()`。**

## 拍板记录（2026-10-21，用户四项裁定）

1. **72 个 PENDING 全部逐步晋升 GOLD**（按插件分批，不抽样）。
2. **VC++ 运行库随包带上**（`msvcp140/vcruntime140/vcruntime140_1`，约 +5 MB），目标机零前提。
3. **文档不一致默认以二进制为准改文档**；行为类缺陷（D1 类）单独走代码修复 + 用例，不混进文档批。
4. **允许合成夹具**：真实数据不够的动作由脚本生成最小输入，落 `build/tmp/`，`data/` 依旧只读；矩阵里显式标注哪些动作用合成夹具。

沿用的既往裁定：不出安装包、不走云端构建、只留 `cmake --install`；不回退/替换依赖；不 push 远端。

## Global Constraints（每条任务隐含全部）

- **判据三层下限**：链路级（rc=0 + 产物非空 + `info` 可再读）→ 关系级（与数据无关的不变量）→ 数值级（GOLD）。每个动作至少关系级；晋升 GOLD 才算"钉住"。
- **数字判据禁止子串包含**（`Contains("feature_count: 2")` 是假绿发生器）；解析失败必须自己红，不许静默归零。
- **否定命题必须有独立载体复验**；"曾绿/曾红"类历史态说法无留痕不得写进文档。
- **`data/` 只读**：每批收尾跑 `find data -newermt 2026-10-19 -type f | wc -l` 必须 = 0。
- 全量 ctest 一律 `-j1`；跑全量期间任何一棵树不许并发构建；构建带 `MSBUILDDISABLENODEREUSE=1`；动构树前硬门控 `tasklist | grep -cE 'MSBuild|gis_tests|ctest'` = 0。
- 还原一律 `cp`，禁止 `git checkout --`；`git add` 逐文件；每任务一个中文 commit。
- **PENDING 计数只许下降**（`CoverageMeta.PendingCountDoesNotGrow` 上限随晋升同步下调）。
- 本机 python 打印非 ASCII 要 `PYTHONIOENCODING=utf-8`；PS 5.1 读 UTF-8 文本必须显式 `-Encoding UTF8`。
- 子代理不得再派子代理、不得写 `~/.qoder-cn`。

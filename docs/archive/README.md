# 历史归档文档

本目录用于存放已退出当前主发布链、但仍需保留以便追溯阶段决策、实施过程和阶段性判断的历史文档。

这些文档不再作为 `v1.0.0` 当前发布面的主入口，但仍可作为历史背景材料查阅。

## 文档列表

- [v0.6.0工作计划](./v0.6.0工作计划.md)
  - 较早阶段的版本工作计划，记录当时的功能缺口判断、分阶段目标和后续落实偏差。
- [后续工作计划](./后续工作计划.md)
  - 面向后续接手的总入口，重点说明项目现状、阶段判断、模块成熟度差异和下一轮推进顺序。
- [性能与任务执行优化实施计划](./性能与任务执行优化实施计划.md)
  - 聚焦取消链路、进度节流和任务执行模型的专项改造方案，偏工程稳定性与执行体验。
- [算法工作台整改执行计划](./算法工作台整改执行计划.md)
  - 承接“算法工作台”定位后的整改计划，明确本轮问题优先级、执行边界和首批落点。
- [GUI_CLI_底层对齐验证清单](./GUI_CLI_底层对齐验证清单.md)
  - 汇总 GUI、CLI 与底层插件三层对齐的验证证据、已知边界与收口结论。

## 建议阅读顺序

1. 先看 [后续工作计划](./后续工作计划.md)，把握项目阶段和整体排期逻辑。
2. 再看 [算法工作台整改执行计划](./算法工作台整改执行计划.md)，理解后续整改为何这样排序。
3. 需要验证依据时看 [GUI_CLI_底层对齐验证清单](./GUI_CLI_底层对齐验证清单.md)。
4. 需要追溯更早方案时，再参考 [v0.6.0工作计划](./v0.6.0工作计划.md) 与 [性能与任务执行优化实施计划](./性能与任务执行优化实施计划.md)。

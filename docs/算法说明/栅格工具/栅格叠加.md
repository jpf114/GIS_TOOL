# 栅格工具 / 栅格叠加

## 功能说明

对两幅栅格按指定方式执行逐像元叠加运算，支持算术叠加、逻辑叠加和条件表达式。

## 输入与输出

- 输入：两幅栅格（主影像 + 叠加影像）
- 输出：叠加结果栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 主输入栅格 |
| 叠加影像 | 文件路径 | 是 | 无 | 叠加分析的第二幅影像 |
| 输出文件 | 文件路径 | 是 | 无 | 输出叠加结果 |
| 叠加方式 | 枚举 | 否 | `max` | 见下方叠加方式说明 |
| 条件表达式 | 字符串 | 否 | 无 | 仅叠加方式为 cond 时生效 |

### 叠加方式说明

| 方式 | 含义 | 公式 |
| --- | --- | --- |
| `max` | 取最大值 | `max(A, B)` |
| `min` | 取最小值 | `min(A, B)` |
| `mean` | 取平均值 | `(A + B) / 2` |
| `sum` | 求和 | `A + B` |
| `subtract` | 相减 | `A - B` |
| `multiply` | 相乘 | `A × B` |
| `divide` | 相除 | `A / B`（B=0 时结果为 0） |
| `and` | 逻辑与 | `A>0 且 B>0 → 1，否则 → 0` |
| `or` | 逻辑或 | `A>0 或 B>0 → 1，否则 → 0` |
| `cond` | 条件表达式 | 满足条件 → 1，否则 → 0 |

### 条件表达式语法

仅叠加方式为 `cond` 时使用。表达式中 `A` 表示主影像像元值，`B` 表示叠加影像像元值。

支持的运算符：

| 运算符 | 含义 |
| --- | --- |
| `>`, `<`, `>=`, `<=` | 比较 |
| `==`, `!=` | 等于 / 不等于 |
| `&` | 逻辑与 |
| `|` | 逻辑或 |

示例：`A > 100 & B > 50` — 主影像大于 100 且叠加影像大于 50 的像元赋 1，其余赋 0。

## 算法内容

逐像元叠加是栅格栅格代数运算的基础。与 ArcGIS Raster Calculator 中的条件运算和 QGIS Raster Calculator 中的栅格叠加功能一致。

当前实现按两幅影像的空间交集逐像元计算，对每个像元执行所选的叠加运算。条件表达式模式额外支持用户自定义逻辑条件，适合做适宜性评价中的多因子叠加分析。

## 处理流程

1. 打开主影像和叠加影像。
2. 对齐两幅影像的空间范围，取交集像元。
3. 根据叠加方式对每个像元执行对应运算。
4. 若选择 cond 模式，先解析条件表达式为有序比较-逻辑操作链。
5. 对每个像元代入主影像和叠加影像的实际值进行条件求值。
6. 逐波段写出结果栅格，保留主影像的空间参考和地理变换。

## 输出说明

- 输出范围为两幅影像的空间交集。
- 输出波段数取二者较小值，逐波段叠加。
- 结果保留主影像的空间参考。

## 结果解释

- `max`/`min`：适合取两期数据中的较好/较差值。
- `sum`/`subtract`：适合变化检测（如作差分析）。
- `and`/`or`：适合二值化叠加的布尔运算。
- `cond`：适合自定义多因子判断逻辑。

## 适用场景

- 两期 DEM 差值的填挖方分析。
- 多因子栅格叠加的适宜性评价。
- 二值化掩膜的布尔叠加。
- 自定义条件的区域筛选。

## 推荐输出文件名

- `raster_overlay_result.tif`

## 注意事项

- 两幅影像应具有相同或可匹配的空间参考。
- 叠加结果仅在两幅影像重叠区域内有效。
- divide 模式下除数接近 0 的像元结果为 0。

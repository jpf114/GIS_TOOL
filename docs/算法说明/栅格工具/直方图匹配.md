# 栅格工具 / 直方图匹配

## 功能说明

将输入影像指定波段的灰度分布匹配到参考影像，使输出结果在整体亮度和对比度上更接近参考影像。

## 输入与输出

- 输入：待匹配栅格、参考栅格
- 输出：匹配后的栅格结果，建议使用 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 待执行匹配的输入栅格。 |
| 参考文件 | 文件路径 | 是 | 无 | 提供目标灰度分布的参考栅格。 |
| 输出文件 | 文件路径 | 是 | 无 | 输出匹配结果。 |
| 波段号 | 整数 | 否 | `1` | 从 `1` 开始。 |

## 算法内容

直方图匹配用于让输入影像指定波段的灰度分布尽量接近参考影像。当前实现会先把输入和参考波段归一化到 8 位灰度，再分别统计两者直方图和累计分布函数，构建一张 256 级查找表，最后把输入影像映射到参考影像的灰度分布上。

取档规则（批次 D R3a 现读产品代码里的 `buildHistogramMatchLut` 后写清，避免按『教科书直方图匹配』理解）：

- 两侧的累计分布函数都按 **`<= v` 的累积计数 / 像元总数**算；两侧各按各的 `min`/`max` 归一到 8 位，
  标度是 `255/(max-min)`——链路里**没有直方图裁剪也没有百分位步骤**，极值不会被削掉。
- 查表游标**只单调前进**，前进条件是『参照累计值 严格小于 输入累计值』⇒ 命中的是**第一个累计值不小于输入的档**，**并列时取低的那一档**；参照里的空档（该值一个像元都没有）沿用上一次的结果。
  并列往哪边取是真会改产物的：批次 D R3a 的臂把这条 `<` 翻成 `<=`，实测输出 Min 从 0 变 85、
  均值从 148.75 变 212.5，不是『差不多』级别的差别。

两条容易被当成『能调』其实调不了的形状：

- **`波段号` 同时用于输入和参照**（产品里两次 `gdalBandToMat` 用的是同一个号），所以
  『拿同一个文件的不同波段当参照』这个用法拼不出来，参照必须是**另一个文件**。
- **产物不是原始辐射单位**：匹配结果是 `0..255` 的**整数值**，只是存成了 `GDT_Float32` 单波段写出。
  后面要按物理量统计的动作不能直接吃这个产物。
- 参照尺寸与输入不一致时，产品先把参照按 `INTER_LINEAR` 重采样到输入尺寸再统计它的直方图，
  所以『尺寸不等的参照』会让目标分布本身带上插值痕迹；两侧同尺寸时不走这一步。

## 处理流程

1. 打开输入栅格和参考栅格，并读取指定波段。
2. 如果参考影像尺寸与输入不一致，则先把参考影像重采样到输入尺寸。
3. 将输入波段和参考波段分别归一化到 `0-255` 的 8 位范围。
4. 统计两者的直方图和累计分布函数。
5. 根据累计分布函数关系构造 256 级灰度映射查找表。
6. 用该查找表把输入影像灰度映射到参考分布。
7. 将结果转换为浮点栅格并写出，同时保留输入影像的空间参考和地理变换。

## 注意事项

- 当前按单波段执行匹配，未指定时默认使用第 1 波段。
- 输入栅格与参考栅格应具有可比较的数据分布，极端异常值会影响匹配效果。
- 当前输出固定为 GTiff。

## 输出说明

- 输出结果为栅格文件。
- 建议优先使用 `.tif` 保存，便于后续在 CLI、GUI 或 GIS 软件中继续处理。

## 结果解释

- 输出影像的整体亮度和对比度分布会更接近参考影像。
- 该过程调整的是灰度分布，不保证空间纹理或绝对物理意义与参考完全一致。

## 适用场景

- 多景影像视觉一致化、亮度风格统一和显示前处理。

# 栅格工具 / 重分类

## 功能说明

将栅格像元值按自定义规则映射为新值，支持单值映射和区间映射两种模式。

## 输入与输出

- 输入：单波段或多波段栅格
- 输出：重分类后的结果栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入栅格 |
| 输出文件 | 文件路径 | 是 | 无 | 输出重分类结果 |
| 重分类规则 | 字符串 | 否 | 空 | 每行一条，格式 `旧值:新值` 或 `旧最小值,旧最大值:新值`；`重分类模式=manual`（默认）时必填，缺失时动作报错 `reclass_rules is required for manual mode` |
| 重分类模式 | 枚举 | 否 | `manual` | `manual` 按上面的规则逐条映射；`interval` 按 `间隔步长` 等距切分 |
| 间隔步长 | 浮点数 | 否 | `1.0` | 仅 `重分类模式=interval` 时生效，必须大于 0，否则报错 `interval_step must be positive` |
| 默认值 | 浮点数 | 否 | `0.0` | 未匹配规则时的默认填充值 |
| 保留未匹配 | 布尔值 | 否 | `true` | 勾选=保留原值，不勾选=赋默认值 |

### 规则格式说明

- **单值映射**：`1:10` 表示原值 1 映射为新值 10
- **区间映射**：`2,5:20` 表示原值在 2 到 5（含）区间内映射为新值 20
- 多条规则使用换行分隔

```
# 示例规则
1:10
2,5:20
6,9:30
```

## 算法内容

重分类本质是逐像元的查表映射过程。每个像元值依次匹配所有规则，取第一个符合的规则的目标值赋给该像元。如果没有任何规则匹配，则根据"保留未匹配"参数决定保留原值还是赋默认值。

`重分类模式=interval` 时不需要手写规则：先逐波段扫描取值范围（跳过 NoData 像元），把起点下取整到 `间隔步长` 的整倍数，再从该起点起按步长切出 `[current, current+step)` 的连续区间，依次编号为 1、2、3… 作为新值。区间规则**逐波段独立生成**，不跨波段共用一份，否则后一个波段会先命中前一个波段推入的区间。

与 ArcGIS Spatial Analyst 的 Reclassify 工具的核心逻辑一致，属于栅格代数中的条件重赋值操作。当前实现已覆盖单值映射和区间映射两种最常用的重分类模式。

## 处理流程

1. 打开输入栅格，读取空间参考和波段数。
2. 按 `重分类模式` 生成规则：`manual` 解析重分类规则文本，`interval` 逐波段扫描范围并等距切分。
3. 遍历每个波段，按规则逐像元查表。
4. 对每波段生成重分类后的浮点栅格。
5. 写出包含全部波段的结果栅格，保留原始空间参考和地理变换。

## 输出说明

- 输出结果为多波段浮点栅格。
- 输出波段数与输入一致，每个波段独立重分类。
- 保留输入栅格的空间参考和地理变换。

## 结果解释

- 未匹配像元在"保留未匹配"模式下保持原值，否则填充默认值。
- 输出值的语义完全由重分类规则定义，适合将连续值映射为离散类别或调整数值范围。

## 适用场景

- DEM 高程分级（坡度分级、高程带划分）。
- 土地利用重编码。
- 适宜性评价中的数值标准化。
- 坡度、坡向等派生栅格的分级显示预处理。

## 推荐输出文件名

- `raster_reclass_result.tif`

## 注意事项

- 规则应按优先级顺序编写，因为匹配到第一条规则后即停止。
- 默认值和"保留未匹配"互斥：勾选"保留未匹配"时默认值参数不生效。
- 单波段映射和多波段映射规则相同，每个波段独立处理。

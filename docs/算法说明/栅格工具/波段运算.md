# 栅格工具 / 波段运算

## 功能说明

按表达式对多波段栅格执行像元级计算，适合做波段加权、简单指数和线性组合。

## 输入与输出
- 输入：多波段栅格
- 输出：单波段结果栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入多波段栅格 |
| 输出文件 | 文件路径 | 是 | 无 | 输出运算结果 |
| 表达式 | 字符串 | 是 | 无 | 例如 `B1+B2`、`B1*0.5+B2*0.5` |

## 算法内容

波段运算用于对多波段栅格执行逐像元表达式计算。当前实现支持 `B1`、`B2` 这类波段占位符，以及基础四则运算和括号。它会先读取全部波段，再对每个像元代入表达式求值，生成单波段结果栅格。

## 处理流程

1. 打开输入多波段栅格。
2. 读取全部波段到内存。
3. 对每个像元构造一组 `B1/B2/...` 变量值。
4. 先把表达式**编译成逆波兰节点序列**（波段变量在编译期就解析成下标），再逐像元求值 —— 不存在"把占位符做文本替换"这一步。⇒ 表达式非法（含未知变量）时在**读取任何像元之前**就显式失败 `Expression error in "<表达式>": <原因>`，不会静默交回 0.0。
5. 按四则运算和括号规则求值，得到该像元输出值。
6. 对整幅影像逐像元重复计算。
7. 将结果写出为单波段浮点栅格，并保留原始栅格空间参考和地理变换。

## 输出说明

- 表达式中的波段占位符使用 `B1`、`B2`、`B3` 这种形式
- 当前支持基础四则运算和括号
- 输出保留输入栅格的空间参考和地理变换
- **不建 NoData 掩膜**：各波段 NoData 原值（`-9999`、`3.4e38` 等）作为普通数值参与表达式，NoData 位置留下的是算术结果；写出时只把**输入第 1 波段声明的 NoData 值**写成输出数据集的 NoData 元数据 ⇒ 表达式的合法结果若恰好等于该声明值会被下游误判为 NoData。

## 结果解释

- 输出值含义完全由表达式决定。
- 除法判的是**绝对阈值**：`|除数| < 1e-15` 即视为除零 —— 整条表达式求值中止并把该像元写成**合法数值 0.0**（不是 NoData），只在元数据里以 `divide_by_zero_pixels` 计数。⇒ 量级 ≲1e-14 的波段（如归一化到极小值的反射率）会把良好比值误判成除零；下游也无法从栅格本身区分"真 0"与"除零 0"。

## 适用场景

- 波段线性组合、简单指数试验和快速像元级栅格计算。

## 推荐输出文件名
- `band_math_result.tif`

## 注意事项

- 表达式引用的波段号必须落在输入栅格实际波段范围内
- 除法分母接近 0 时按"结果解释"里的口径处理：该像元写 `0.0` 并计入 `divide_by_zero_pixels`，不写 NoData

# 栅格工具 / 欧氏距离

## 功能说明

计算栅格中每个背景像元到最近目标像元的欧氏距离，生成距离栅格。

## 输入与输出

- 输入：二值化掩膜栅格（目标=非零，背景=零）
- 输出：欧氏距离栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入二值栅格（目标=255，背景=0） |
| 输出文件 | 文件路径 | 是 | 无 | 输出距离栅格 |
| 最大距离 | 浮点数 | 否 | `0.0` | 最大搜索距离（0=无限制，单位=像元实际单位） |

## 算法内容

欧氏距离（Euclidean Distance / Proximity）计算每个背景像元到最近的目标像元的直线距离。本质上是对二值化掩膜执行距离变换。

与 ArcGIS Spatial Analyst 的 "Euclidean Distance" 工具和 QGIS 的 "Proximity (raster distance)" 功能一致。

当前实现使用 OpenCV 的 `distanceTransform` 函数，算法为：

1. 对输入二值化栅格执行距离变换，使用 `cv::DIST_L2`（欧氏距离范数）。
2. 结果自动乘以像元地面分辨率，得到实际地理距离。
3. 若设置了最大距离上限，超出该值的距离按上限截断。

`cv::DIST_MASK_PRECISE` 保证输出精度，与 ArcGIS 欧氏距离工具输出精度一致。

## 处理流程

1. 打开输入栅格，识别目标像元（值非零）和背景像元（值为零）。
2. 构建 NoData 掩膜，排除 NoData 区域。
3. 将目标区域二值化（目标=255，背景=0）。
4. 调用 OpenCV `distanceTransform` 计算逐像元欧氏距离。
5. 将像素距离乘以像元地面分辨率，转换为实际地理单位距离。
6. 若设置了最大距离，超出上限的值截断为上限。
7. 写出距离栅格，保留输入栅格的空间参考和地理变换。

## 输出说明

- 输出为浮点栅格，像元值表示该位置到最近目标像元的地理距离。
- 目标像元自身的距离值为 0。
- 距离单位与输入栅格的空间参考单位一致（如米、度）。

## 结果解释

- 距离值越大表示越远离目标区域。
- 距离值的变化率反映目标边界的空间分布。
- 叠加距离分类可提取不同距离级别的缓冲区。

## 适用场景

- 保护区缓冲区分析（计算各位置到保护区边界距离）。
- 河流/道路沿线距离分级。
- 污染源扩散距离模型的基础输入。
- 城市绿地可达性分析的中间数据。

## 推荐输出文件名

- `euclidean_distance_result.tif`

## 注意事项

- 输入应为二值化栅格，值域简洁明确（如 0/1 或 0/255）。
- 使用投影坐标系确保距离单位有意义（地理坐标系的距离单位为度）。
- 最大距离参数可有效约束计算量，但超出范围的像元距离值会统一截断。
- 距离计算考虑 NoData 掩膜，NoData 区域不参与距离计算。

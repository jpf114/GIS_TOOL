# 栅格工具 / 欧氏距离

## 功能说明

计算栅格中每个像元到最近目标像元的欧氏距离，生成距离栅格。目标像元自身的距离为 0，NoData 像元输出 NoData。

## 输入与输出

- 输入：栅格（目标=值非 0 且非 NoData，背景=值为 0）；多波段输入逐波段独立计算
- 输出：欧氏距离栅格，波段数与输入一致，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入栅格（目标=值非 0 且非 NoData，背景=0） |
| 输出文件 | 文件路径 | 是 | 无 | 输出距离栅格 |
| 最大距离 | 浮点数 | 否 | `0.0` | 最大搜索距离（0=无限制，单位=像元实际单位） |

## 算法内容

欧氏距离（Euclidean Distance / Proximity）计算每个像元到最近目标像元的直线距离。本质上是对目标掩膜执行距离变换。

与 ArcGIS Spatial Analyst 的 "Euclidean Distance" 工具和 QGIS 的 "Proximity (raster distance)" 功能一致。

当前实现使用 OpenCV 的 `distanceTransform` 函数，算法为：

1. 逐波段构造目标掩膜：值非 0 且不是该波段 NoData 的像元是目标。
2. 对掩膜取反后交给 `cv::distanceTransform`（它度量的是非零像元到最近零像元的距离，因此零像元必须是目标），度量方式 `cv::DIST_L2`。
3. 结果自动乘以像元地面分辨率，得到实际地理距离。
4. 若设置了最大距离上限，超出该值的距离按上限截断。
5. 最后把 NoData 像元的输出值写成该波段的 NoData 值。

`cv::DIST_MASK_PRECISE` 保证输出精度，与 ArcGIS 欧氏距离工具输出精度一致。

## 处理流程

1. 打开输入栅格，逐波段识别目标像元（值非 0 且非 NoData）与背景像元（值为 0）。
2. 构造 NoData 有效性掩膜：NoData 像元既不是目标，也不参与目标判定。
3. 对目标掩膜取反，调用 OpenCV `distanceTransform` 计算逐像元到最近目标像元的欧氏距离。
4. 将像素距离乘以像元地面分辨率，转换为实际地理单位距离。
5. 若设置了最大距离，超出上限的值截断为上限。
6. 截断之后再写入 NoData：`max_distance` 的截断会把大于上限的值改写成上限，先写 NoData 会让正的 NoData 值被毁掉。
7. 全部波段计算完成后一次性写出，保留输入栅格的空间参考和地理变换，输出波段数与输入相同。

## 输出说明

- 输出为浮点栅格，像元值表示该位置到最近目标像元的地理距离。
- 目标像元自身的距离值为 0。
- NoData 像元的输出值等于该波段的 NoData 值（NoData 声明随输入波段写到输出）。
- 距离单位与输入栅格的空间参考单位一致（如米、度）。

## 结果解释

- 距离值越大表示越远离目标区域。
- 距离值的变化率反映目标边界的空间分布。
- 叠加距离分类可提取不同距离级别的缓冲区。

## 适用场景

- 保护区缓冲区分析（计算各位置到保护区边界距离）。
- 河流/道路沿线距离分级。
- 污染源扩散距离模型的基础输入。
- 城市绿地可达性分析的中间数据。

## 推荐输出文件名

- `euclidean_distance_result.tif`

## 注意事项

- 输入不必是 0/255 二值栅格：任何非 0 且非 NoData 的值都被当作目标（包括负的 DN、负反射率、地形凹槽）。
- 使用投影坐标系确保距离单位有意义（地理坐标系的距离单位为度）。
- 最大距离参数可有效约束计算量，但超出范围的像元距离值会统一截断；该截断不影响 NoData 像元（NoData 在截断之后写入）。
- 距离计算考虑 NoData 掩膜：NoData 像元不作为目标，其输出值为该波段的 NoData 值。
- 某个波段整幅都是背景（没有任何目标像元）时，`cv::distanceTransform` 在该波段输出固定值 65536（实测值，与像元位置无关，且同样会被 `max_distance` 截断），而不是 0 或空值。

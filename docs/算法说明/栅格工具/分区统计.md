# 栅格工具 / 分区统计

## 功能说明

按矢量面要素对栅格进行分区统计，输出每个要素区域内的统计指标（最小值、最大值、均值、标准差、总和、像元数）。

## 输入与输出

- 输入：栅格 + 面矢量文件
- 输出：JSON 或 CSV 格式的统计结果

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入栅格 |
| 矢量分区文件 | 文件路径 | 是 | 无 | 面矢量分区文件 |
| 输出文件 | 文件路径 | 是 | 无 | 输出统计结果（`.json` 或 `.csv`） |
| 要素 ID 字段 | 字符串 | 否 | 空 | 矢量中标识每个分区的字段名，留空使用 FID |

## 算法内容

分区统计（Zonal Statistics）是栅格 GIS 中的核心分析功能。计算原理为：对矢量图层中的每个面要素，提取其空间覆盖范围内的所有栅格像元值，然后按波段逐区计算系列统计量。

此功能的计算方式与 ArcGIS Spatial Analyst 的 "Zonal Statistics as Table" 工具和 QGIS 的 "Zonal statistics" 工具一致，均基于矢量分区叠加栅格提取的逐像元方法。

输出的统计指标包括：

| 指标 | 说明 |
| --- | --- |
| min | 区域内最小值 |
| max | 区域内最大值 |
| mean | 区域内算术平均值 |
| stddev | 区域内标准差 |
| sum | 区域内值总和 |
| count | 区域内有效像元数（排除 NoData） |

## 处理流程

1. 打开输入栅格，获取空间参考和地理变换参数。
2. 打开矢量文件，读取第一个图层。
3. 遍历每个面要素：
   a. 根据要素的边界信封（Envelope）截取栅格子范围。
   b. 对该范围内每个像元，测试是否被当前要素几何包含。
   c. 对于被包含的像元，排除 NoData 值后累计各统计量。
4. 根据输出格式写入 JSON 或 CSV。

### JSON 输出示例

```json
{
  "zone_A": [
    {
      "band": 1,
      "min": 100.5,
      "max": 850.3,
      "mean": 325.7,
      "stddev": 142.1,
      "sum": 65140.0,
      "count": 200
    }
  ]
}
```

### CSV 输出示例

```csv
feature_id,band,min,max,mean,stddev,sum,count
zone_A,1,100.5,850.3,325.7,142.1,65140.0,200
```

## 输出说明

- `.json`：结构化的嵌套 JSON，按要素 ID → 波段顺序组织。
- `.csv`：每行一条统计记录，包含要素 ID 和波段号。
- 没有有效像元的分区不输出统计值。

## 结果解释

- `min`/`max` 越接近表示区域内像元值越均匀。
- `stddev` 越大表示区域内变异越大。
- `count = 0` 的分区在输出中不出现任何统计值。

## 适用场景

- 流域汇总（按子流域统计 DEM 的高程特征）。
- 行政区域汇总（按区划统计土地利用或 NDVI 特征）。
- 样方分析（按采样网格统计植被指数分布）。
- 栅格重分类后的面积统计。

## 推荐输出文件名

- `zonal_stats_result.json`
- `zonal_stats_result.csv`

## 注意事项

- 大数据量时逐像元包含测试计算量大，建议分区数量不超过 500 个。
- 栅格和矢量应使用相同的空间参考。
- 跨越像元边界的要素按像元中心点判定归属。
- 可使用"要素 ID 字段"指定矢量中已存在的唯一标识列。

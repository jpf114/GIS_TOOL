# 几何校正与辐射处理 / 百分位拉伸

## 功能说明

按多波段亮暗百分位对输入影像执行线性拉伸归一化，将各波段值域映射到 [0, 1] 区间。

## 输入与输出

- 输入：多波段栅格
- 输出：多波段浮点栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入影像 |
| 输出文件 | 文件路径 | 是 | 无 | 输出拉伸结果 |
| dark_percentile | 浮点数 | 否 | `1.0` | 暗端百分位（0-100） |
| bright_percentile | 浮点数 | 否 | `99.0` | 亮端百分位（0-100） |

## 算法内容

百分位拉伸（Percentile Linear Stretch）是一种基于统计分位数的对比度拉伸方法：

1. 对每个波段，统计指定暗端百分位 `P_dark` 和亮端百分位 `P_bright` 对应的像元值 `V_dark` 和 `V_bright`
2. 对所有像元执行线性映射：`output = (input - V_dark) / (V_bright - V_dark)`
3. 将结果截断到 [0, 1] 区间

该方法不依赖外部大气模型，属于辐射归一化而非大气校正。

## 处理流程

1. 打开输入多波段栅格。
2. 检查 `dark_percentile` 和 `bright_percentile` 的取值是否合理，并保证前者小于后者。
3. 按波段逐个读取输入数据。
4. 对每个波段统计指定暗百分位和亮百分位对应的像元值。
5. 从该波段所有像元中减去暗百分位值。
6. 将减法后小于 0 的结果截断为 0。
7. 以"亮百分位值 - 暗百分位值"作为当前波段的有效范围，对结果归一化。
8. 若有效范围过小，则该波段输出全 0。
9. 再把结果上限截断到 1，保证输出在 `0` 到 `1` 范围内。
10. 将所有处理后的波段合并写出为多波段浮点栅格。

## 输出说明

- 各波段会分别执行亮暗拉伸和归一化
- 输出值会被限制到 `0` 到 `1`

## 结果解释

- 输出值表示各波段在本波段亮暗范围内的相对归一化结果。
- 由于每个波段独立按分位值归一化，结果更适合做后续相对分析，而不是严格物理反射率解释。
- `dark_percentile` 和 `bright_percentile` 的设置会直接影响拉伸力度与对极端值的敏感程度。

## 适用场景

- 多波段影像快速预处理与对比度增强。
- 缺少完整大气参数时的轻量归一化。
- 为后续显示、指数计算或分类准备更平衡的输入数据。

## 推荐输出文件名

- `percentile_stretch_result.tif`

## 注意事项

- `dark_percentile` 必须小于 `bright_percentile`
- 本方法为百分位线性拉伸，非大气校正

# 光谱指数 / NDVI

## 功能说明

根据红光与近红外波段计算 NDVI。

## 输入与输出

- 输入：多波段栅格
- 输出：NDVI 栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入多波段影像。 |
| 输出文件 | 文件路径 | 是 | 无 | 输出 NDVI。 |
| 红光波段 | 整数 | 否 | `3` | 红光波段序号。 |
| 近红外波段 | 整数 | 否 | `4` | 近红外波段序号。 |

## 算法内容

NDVI（归一化植被指数 / Normalized Difference Vegetation Index）是遥感领域最广泛使用的植被指数，用于反映植被覆盖度和生长状况。其核心原理基于植被在红光和近红外波段的反射率差异：健康植被强烈吸收红光（用于光合作用）并强力反射近红外（由叶肉细胞结构和含水量决定），而裸土、水体、云等非植被地物在两个波段的反射率差异较小。

### 数学模型

NDVI 通过红光与近红外反射率的归一化差值来量化植被特征：

$$\text{NDVI} = \frac{\rho_{\text{NIR}} - \rho_{\text{RED}}}{\rho_{\text{NIR}} + \rho_{\text{RED}}} = \frac{B_{\text{NIR}} - B_{\text{RED}}}{B_{\text{NIR}} + B_{\text{RED}}}$$

其中：
- \(\rho_{\text{NIR}}\) 为近红外波段反射率（或 DN 值）
- \(\rho_{\text{RED}}\) 为红光波段反射率（或 DN 值）
- \(B_{\text{NIR}}\) 和 \(B_{\text{RED}}\) 为对应波段的像元值

### 值域与物理意义

NDVI 的理论范围为 [-1, 1]：

| NDVI 范围 | 地物类型 | 物理原因 |
|-----------|---------|----------|
| -1 ~ 0 | 水体、云、雪 | NIR 反射率 < RED 反射率 |
| 0 ~ 0.2 | 裸土、建筑物 | RED 和 NIR 差异小 |
| 0.2 ~ 0.5 | 稀疏植被、草地 | 植被开始显现 NIR 优势 |
| 0.5 ~ 0.8 | 密植被、森林 | 强烈 NIR 反射 + 强烈 RED 吸收 |
| > 0.8 | 极密植被（热带雨林） | 极高叶面积指数 |

### 归一化差值的优势

- **比值处理消除光照差异**：归一化形式对地形阴影、太阳高度角变化具有一定的抗干扰能力
- **消除部分大气影响**：分子分母同时受大气衰减影响，除法部分抵消
- **处理流程**：当前实现逐像元读取红光和近红外波段值，按公式计算后写出单波段浮点结果。

### 安全除法处理

当分母 \(B_{\text{NIR}} + B_{\text{RED}}\) 接近零时（如传感器异常或全暗像元），直接除法会产生异常大的数值。当前实现对此类情况进行安全处理：当分母绝对值低于阈值（如 \(10^{-6}\)）时，将该像元结果设为 0（视为无效），避免异常值扩散。

## 处理流程

1. 打开输入多波段栅格。
2. 检查红光波段和近红外波段编号是否在实际波段范围内。
3. 分别读取红光波段和近红外波段的数据。
4. 对每个像元按 `(NIR - Red) / (NIR + Red)` 计算 NDVI。
5. 在分母接近零或不适合直接相除的位置，按安全除法逻辑处理，避免非法数值直接破坏结果。
6. 将计算出的 NDVI 写出为单波段浮点栅格，并记录结果的最小值、最大值以及实际使用的波段号。

## 输出说明

- 输出结果建议使用 `.tif`。
- 计算公式为 `(NIR - Red) / (NIR + Red)`。
- 理论上 NDVI 常见范围在 `-1` 到 `1`，实际结果会受输入数据值范围影响。

## 结果解释

- 值越接近正高值，通常说明植被覆盖更明显、活跃度更高。
- 接近零的区域，往往表示裸地、建筑或植被较弱区域。
- 明显负值通常对应水体、阴影或某些非植被目标。
- 实际判读时应结合传感器类型、波段定义、预处理状态和场景特征，不应只凭单一阈值机械分割。

## 适用场景

- 植被覆盖快速识别。
- 农情、林地、生长状态等基础遥感分析。
- 作为后续阈值分割、分级制图或时序对比的输入指数。

## 推荐输出文件名

- `ndvi_result.tif`
- `植被指数_ndvi.tif`

## 注意事项

- 红光和近红外波段号都必须落在实际波段范围内。
- 结果元数据返回 NDVI 最小值、最大值和实际使用的波段号。

# 光谱指数 / NDVI

## 功能说明

根据红光与近红外波段计算 NDVI。

## 输入与输出

- 输入：多波段栅格
- 输出：NDVI 栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入多波段影像。 |
| 输出文件 | 文件路径 | 是 | 无 | 输出 NDVI。 |
| 红光波段 | 整数 | 否 | `3` | 红光波段序号。 |
| 近红外波段 | 整数 | 否 | `4` | 近红外波段序号。 |

## 算法内容

NDVI（归一化植被指数 / Normalized Difference Vegetation Index）是遥感领域最广泛使用的植被指数，用于反映植被覆盖度和生长状况。其核心原理基于植被在红光和近红外波段的反射率差异：健康植被强烈吸收红光（用于光合作用）并强力反射近红外（由叶肉细胞结构和含水量决定），而裸土、水体、云等非植被地物在两个波段的反射率差异较小。

### 数学模型

NDVI 通过红光与近红外反射率的归一化差值来量化植被特征：

$$\text{NDVI} = \frac{\rho_{\text{NIR}} - \rho_{\text{RED}}}{\rho_{\text{NIR}} + \rho_{\text{RED}}} = \frac{B_{\text{NIR}} - B_{\text{RED}}}{B_{\text{NIR}} + B_{\text{RED}}}$$

其中：
- \(\rho_{\text{NIR}}\) 为近红外波段反射率（或 DN 值）
- \(\rho_{\text{RED}}\) 为红光波段反射率（或 DN 值）
- \(B_{\text{NIR}}\) 和 \(B_{\text{RED}}\) 为对应波段的像元值

### 值域与物理意义

NDVI 的理论范围为 [-1, 1]：

| NDVI 范围 | 地物类型 | 物理原因 |
|-----------|---------|----------|
| -1 ~ 0 | 水体、云、雪 | NIR 反射率 < RED 反射率 |
| 0 ~ 0.2 | 裸土、建筑物 | RED 和 NIR 差异小 |
| 0.2 ~ 0.5 | 稀疏植被、草地 | 植被开始显现 NIR 优势 |
| 0.5 ~ 0.8 | 密植被、森林 | 强烈 NIR 反射 + 强烈 RED 吸收 |
| > 0.8 | 极密植被（热带雨林） | 极高叶面积指数 |

### 归一化差值的优势

- **比值处理消除光照差异**：归一化形式对地形阴影、太阳高度角变化具有一定的抗干扰能力
- **消除部分大气影响**：分子分母同时受大气衰减影响，除法部分抵消
- **处理流程**：当前实现逐像元读取红光和近红外波段值，按公式计算后写出单波段浮点结果。

### 安全除法处理

当前实现的"安全除法"只有一步：**给分母加一个极小量再相除**（`denominator += 1e-10f`，随后 `cv::divide`）。
它**不**做阈值判断，也**不**把可疑像元置 0：

- 在正常量级上这个 1e-10 是被吞掉的（float32 下 `100.0f + 1e-10f` 仍是 `100.0f`）⇒ 常规像元的 NDVI 就是公式值本身，
  不会因为加了它而偏移；
- 只有当分子非 0 而分母为 0（例如 NIR 与 Red 互为相反数）时它才起作用，此时结果是 `分子 / 1e-10` 量级的**有限巨值**
  （实测该形态约 ±1e12）——既不是 NaN、不是无穷，也**不是** 0。

⚠ 后果要说清：这类像元**跳出了 NDVI 的合法值域 [-1, 1]**，而本实现不做值域裁剪 ⇒ 它们会留在产物里，
并把 metadata 的最小/最大值拉到自己那一侧。按行业惯例，这里更常见的做法是把分母接近 0 的像元掩膜成 NoData；
改成那样会改变既有产物的数值，属可观测行为变更 ⇒ **已登记待拍板**，本次只把文档改准到与实现一致。

## 处理流程

1. 打开输入多波段栅格。
2. 检查红光波段和近红外波段编号是否在实际波段范围内。
3. 分别读取红光波段和近红外波段的数据。
4. 对每个像元按 `(NIR - Red) / (NIR + Red)` 计算 NDVI。
5. 分母统一 `+1e-10` 后相除（**不置 0、不做阈值判断**）⇒ 分母为 0 而分子非 0 的像元得到的是一个巨大有限值，
   详见上面"安全除法处理"。
6. 将计算出的 NDVI 写出为单波段浮点栅格，并记录结果的最小值、最大值以及实际使用的波段号。

## 输出说明

- 输出结果建议使用 `.tif`。
- 计算公式为 `(NIR - Red) / (NIR + Red)`。
- 理论上 NDVI 的范围是 `-1` 到 `1`，但**本实现不裁剪值域**：被 1e-10 兜住分母的那些像元会落在 ±1e12 量级 ⇒ 
  统计最小/最大值时会被它们主导，读结果时先确认有没有这种像元。
- 结果的 metadata 给出 `index_min` / `index_max`（另有同值别名 `ndvi_min` / `ndvi_max`）与实际使用的 `red_band` / `nir_band`；
  成功消息里那对方括号区间就是同一对最值。

## 结果解释

- 值越接近正高值，通常说明植被覆盖更明显、活跃度更高。
- 接近零的区域，往往表示裸地、建筑或植被较弱区域。
- 明显负值通常对应水体、阴影或某些非植被目标。
- 实际判读时应结合传感器类型、波段定义、预处理状态和场景特征，不应只凭单一阈值机械分割。

## 适用场景

- 植被覆盖快速识别。
- 农情、林地、生长状态等基础遥感分析。
- 作为后续阈值分割、分级制图或时序对比的输入指数。

## 推荐输出文件名

- `ndvi_result.tif`
- `植被指数_ndvi.tif`

## 注意事项

- 红光和近红外波段号都必须落在实际波段范围内：越界时返回**失败**，文案形如 `red_band 9 out of range (1-4)`
  （键名 + 传入的号 + 实际波段数），且不写出产物。
- 输入文件打不开是**另一种形态**：`openRaster` 在参数校验之外直接抛出，由调用边界统一兜获后转成失败信息 ⇒ 
  同样是"参数不对"，波段越界走失败返回、文件不存在走异常，排查时别混为一谈。
- 结果元数据返回 NDVI 最小值、最大值和实际使用的波段号。

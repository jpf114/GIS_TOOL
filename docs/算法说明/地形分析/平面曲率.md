# 地形分析 / 平面曲率

## 功能说明

按 `3x3` 邻域估算垂直坡向的平面曲率，用于描述等高线方向的收敛与发散趋势。

## 输入与输出

- 输入：DEM 栅格
- 输出：平面曲率结果栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | DEM 输入 |
| 输出文件 | 文件路径 | 是 | 无 | 输出平面曲率栅格 |
| 波段号 | 整数 | 否 | `1` | DEM 波段 |
| Z因子 | 浮点数 | 否 | `1.0` | 高程缩放系数 |

## 算法内容

平面曲率用于描述等高线方向上的收敛与发散趋势。当前实现先在固定 `3x3` 邻域上估计一阶、二阶地形导数，再按平面曲率公式逐像元计算结果。

## 处理流程

1. 打开输入 DEM 并读取指定波段。
2. 按 `z_factor` 对高程进行缩放。
3. 通过 Sobel 等局部导数近似计算一阶导数和二阶导数。
4. 对每个像元计算坡度平方项。
5. 若局部坡度过小，则该像元结果直接写为 0。
6. 否则按平面曲率公式计算结果。
7. 若存在 NoData，则恢复这些位置的 NoData 值。
8. 输出为单波段浮点栅格。

## 注意事项

- 当前实现基于局部一阶、二阶导数近似，适合轻量分析与快速预览
- 可结合剖面曲率一起判读坡面形态

## 输出说明

- 输出结果为单波段浮点栅格。
- 建议优先使用 `.tif` 保存，便于后续在 CLI、GUI 或 GIS 软件中继续处理。

## 结果解释

- 不同符号和数值大小可用于辅助判断地形收敛、发散和侧向形态变化。
- 平坦区域会因为坡度过小而自动趋近于 0。
- ⚠ 上面那条"坡度过小直接写 0"的**早退分支（一阶导平方和 `slopeSq = zx² + zy² < 1e-10` 那一支）今天没有判据**（批次 D D1-T3 登记）。
  它的可判性要分三档说，不许再笼统写成"判不到"：
  - **恰零档（`zx = zy = 0` 严格成立）——恒真，判不到。** 此时分子 `zxx·zy² − 2·zxy·zx·zy + zyy·zx²` 也恒为 0，
    "有早退"（直接写 0）与"把早退删掉"（走 `-0/(0+1e-10) = 0`）两种实现都给 0 ⇒ 任何"平地期望 0"的断言都是**恒真断言**，
    加了它等于没加，还会把"这条分支没人判"这件事洗成"判过了"。今天真的踩在这一档的是
    `PluginTest.TerrainPlanCurvatureHandValueOnUnitPlane` 里常数值 5.0 那幅 `d2_plan_flat.tif` 的
    `EXPECT_NEAR(像元, 0.0f, 1e-4f)`（按产品码那五个 `cv::Sobel` 实参实测：常幅面的 `zx`、`zy`、分子全为 0 ⇒ 该断言对早退支不承重）。
    同一条用例里 unit-plane 那 4 枚 `EXPECT_NEAR(..., 0.0f, 1e-4f)` 靠的是 `zy ≡ 0 ∧ zyy ≡ 0` 的**公式零**：
    姊妹用例 `PluginTest.TerrainProfileCurvatureHandValueOnUnitPlane` 在**同一幅面、同一像元** `(x=0, y=7)` 上断言
    profile 是非零的 `-2.8621670`（±1e-4），而早退支对 profile 与 plan 都写 0 ⇒ 该像元根本没走进早退支，
    这 4 枚连"恒真"都算不上，是与这条分支无关。
  - **小斜率档（`0 < slopeSq < 1e-10`）——可判，不是判不到。** 删早退与留早退的差值 `Δ = |num| / (slopeSq^1.5 + 1e-10)`；
    由 `zx² ≤ s`、`zy² ≤ s`、`2|zx||zy| ≤ zx² + zy² = s`（AM-GM）得 `|num| ≤ s·(|zxx| + |zxy| + |zyy|)`，于是
    `Δ ≤ 0.99999·(|zxx| + |zxy| + |zyy|)`（`g(s) = s/(s^1.5 + 1e-10)` 在该区间单调增，上确界在区间顶端
    `s → 1e-10⁻` 取到 `1e-10/(1e-15 + 1e-10) = 1/(1+1e-5) = 0.99999`）——**这个上界就是二阶导绝对值之和本身，不是某个小量**。
    用产品码同形的 `cv::Sobel`（`zx/zy` 用 `scale=1/8`、`zxx/zyy` 用 `scale=1`、`zxy` 用 `scale=1/4`、`BORDER_REPLICATE`）
    —— **本节出现的"实测"一律指这台同形参考模型的复算，未跑变异后的产品二进制**
    （"把早退支删掉"这条变异臂本批没做，所以"能红"是由差值 `Δ` 与容差的关系**推**出来的，不是臂证）：
    在一幅 `z = (x−δ)² + (y−δ)²`、格距 1、crest 偏 `δ = 1e-6` 的 float32 面上实测：crest 像元
    `zx = −1.967e-6`、`zy = −2.027e-6`、`zxx = zyy = 8.0`、`zxy = 0` ⇒ `slopeSq = 7.976e-12`（确在早退区间内）、**`Δ = 0.638`**，
    比腿侧容差 `2e-3` 大两个数量级以上 ⇒ "把早退支删掉"这种变异在这一档是能红的。
  - **本批裁定仍然是不造这个夹具**，但理由换成与上面两档一致的话：它**可判**，只是要专门新造一枚亚像素 crest/鞍部顶点面，
    期望必须从 float32 量化后的输入手推——`δ` 取 `5e-7 ~ 3e-6` 时实测 `Δ = 0.146 ~ 5.68`，量化让 `Δ` 相对精确值偏 `0.3% ~ 9.1%`，
    所以断言容差得放宽到 `1e-2` 档才吃得住；这份代价与批次 D"把已有覆盖面收口登记"的射程不匹配 ⇒ 排在 D1 之后。
  同一处代码也服务剖面曲率（`剖面曲率.md` 流程第 5 步是同一处早退），所以那条按同样的三档登记。
  旧文把这条与 `-b`（z_factor 空参那条）、ROUGHBORDER（形态学补边模式）、tri 的 `std::clamp` 邻域并成同一档、
  都说成"实现结构上没人能判、不是漏写"——那句已被上面这档复算否证，**撤销**；本条的位置是"可判，但本批不造夹具"。

# 地形分析 / 填挖方

## 功能说明

比较当前 DEM 与参考 DEM，输出高差栅格，并统计填方、挖方和净体积。

## 输入与输出

- 输入：
  - 输入文件：当前 DEM
  - 参考文件：参考 DEM
- 输出：高差结果栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 参考文件 | 文件路径 | 是 | 无 | 参考 DEM |
| 输入文件 | 文件路径 | 是 | 无 | 当前 DEM |
| 输出文件 | 文件路径 | 是 | 无 | 输出高差栅格 |
| 波段号 | 整数 | 否 | `1` | 使用的 DEM 波段 |

## 算法内容

填挖方用于比较两个 DEM 之间的高程差异，并进一步估算填方量、挖方量和净体积。当前实现把“输入 DEM - 参考 DEM”作为高差结果，并按像元面积对正负高差分别积分。

## 处理流程

1. 打开输入 DEM 和参考 DEM，并检查指定波段。
2. 检查两者栅格尺寸是否一致。
3. **两侧各必须取到地理变换**，取不到即失败（`input raster geotransform is missing` / `reference raster geotransform is missing`）；都取到后再逐系数比较（容差 1e-9），不一致即失败。
4. 读取两个 DEM 的对应波段。
5. 逐像元计算高差：`输入 DEM - 参考 DEM`。
6. 根据栅格地理变换计算单个像元面积。
7. 对高差大于 0 的部分累计填方体积，对高差小于 0 的部分累计挖方体积。
8. 输出高差栅格，并在元数据中记录填方、挖方和净体积。

## 输出说明

结果元数据中会附带：

- `fill_volume`
- `cut_volume`
- `net_volume`

## 结果解释

- 输出栅格中的正值表示输入 DEM 高于参考 DEM，负值表示输入 DEM 低于参考 DEM。
- `fill_volume` 表示正高差部分累计得到的填方体积。
- `cut_volume` 表示负高差部分累计得到的挖方体积。
- `net_volume` 为填方减去挖方后的净结果。
- `invalid_pixels` 是被排除在体积积分之外的像元数（该键恒出现，为 0 时也写）。

## 适用场景

- 土方量分析、施工前后地形对比和场地整形评估。

## 注意事项

- 输入 DEM 与参考 DEM 的尺寸必须一致。
- 两幅 DEM 都必须有地理变换（缺任一侧直接失败，**不会**按单位阵继续算下去），且两侧必须一致。
- 体积累加**只统计有效像元**：两侧任一声明的 NoData 哨兵都被排除（判据用 `GetNoDataValue` 的 found 出参，不看值本身），被排除的像元数由元数据键 `invalid_pixels` 给出。含 NoData 边缘的 DEM 其体积会明显小于"看着像全图"的预期。
- 输出值为 `输入 DEM - 参考 DEM`。

## 推荐输出文件名

- `terrain_cut_fill_result.tif`

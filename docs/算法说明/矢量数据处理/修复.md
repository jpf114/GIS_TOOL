# 矢量数据处理 / 修复

## 功能说明

尝试修复输入图层中的非法几何，并把可修复结果写出到新图层。

## 输入与输出

- 输入：矢量图层
- 输出：修复后的矢量图层

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入矢量数据 |
| 输出文件 | 文件路径 | 是 | 无 | 修复结果输出路径 |
| 图层名 | 字符串 | 否 | 无 | 目标图层名 |

## 算法内容

本动作逐条读取并复制要素几何。若某条几何原本有效则直接复制；若原本无效则尝试标准化与几何修复（本质上是 `MakeValid`）。**几何为 NULL、EMPTY（空但非 NULL）或修复失败的要素一律不写出，计入跳过数量**；原本有效的与修复后才有效的才计入修复数量。输出字段结构和空间参考原样保留。
自 N158 起，本动作是全插件**唯一显式允许"维度退化"**的动作：修复成功但维度低于输入（坏面被修成线/点）的结果照样算修复成功并写出（`repaired_count` 计入）——repair 的语义就是"修成什么都算成功"，丢掉降级结果等于废掉它；其余动作默认把这一类按输入不可用丢弃（见并集/差集/交集/矢量裁切的 `*_degraded_input_count`）。

## 处理流程

1. 打开输入图层。
2. 创建输出图层并复制字段结构。
3. 逐条读取输入要素。
4. 对几何执行标准化：
   - 有效几何直接复制；
   - 非法几何尝试自动修复；
   - 几何为 NULL、EMPTY 或修复失败则跳过（EMPTY 不写出，也不计入修复数量）；
5. 把修复后的几何和原字段写入结果图层。
6. 返回修复数量和跳过数量。

## 结果解释

- `repaired_count`：成功写出到结果图层的要素数量（原本有效的 + `MakeValid` 后才有效的；**不含 EMPTY**）
- `skipped_count`：由于几何为 NULL、**EMPTY** 或修复失败而被跳过的要素数量
- 输出字段与输入一致
- 输出并不保证“所有问题都被修复”，只表示当前实现能写出的部分已经被接受

## 适用场景

- 叠加分析前先清理非法面
- 导入外部矢量数据后做一次快速几何修复
- 为拓扑检查、缓冲、融合等操作准备更稳定的输入

## 输出说明

- 输出图层保留输入字段结构和空间参考
- 写出的是“复制成功”的要素：原本有效的与修复后才有效的都算；**EMPTY 几何不在其中**（归跳过）
- `skipped_count` 包含几何为 NULL、EMPTY 或 `MakeValid` 失败的要素

## 推荐输出文件名

- `repair_result.gpkg`

## 注意事项

- 当前实现不会保留失败要素的占位记录，失败要素会被直接跳过
- 结果消息中的修复数量包含“原本有效直接复制”的要素
- 若需要区分“原本有效”和“真正调用修复后有效”的要素，当前实现没有单独字段或统计
- 自 N158 起"修复成功但维度低于输入"这一类输入在**其余动作**里都改按不可用丢弃，但只有叠加四动作
  （union / difference / intersect / clip）有专用 `*_degraded_input_count` 键：boundary / centroid /
  convex_hull / envelope / interior_point / endpoints_extract / midpoints_extract / vertices_extract /
  singlepart / sliver_remove 十个动作的既有 `skipped_count` 会把这类丢弃一并计入（无专用键，看该键变化即可诊断）；
  `duplicate_point_check` 有同族 `skipped_geometry_count` 但其图层闸只放点层、这类丢弃实际到不了；
  `adjacency` / `overlap_check` / `topology_check` / `dangling_endpoint_check` / `dissolve`
  键上无输入侧计数、丢弃静默，诊断只能对比改前改后的产物要素数或检查输出
  （逐动作登记见 `docs/RELEASE.md` 的 N158 节行为变更清单）

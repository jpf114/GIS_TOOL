# 矢量数据处理 / 矢量裁切

## 功能说明

使用裁切图层的空间范围对输入图层做几何裁切，只保留落在裁切区域内的部分。

## 输入与输出

- 输入：
  - 输入矢量图层
  - 裁切矢量图层
- 输出：裁切结果图层，建议使用 `.gpkg`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 待裁切的矢量数据 |
| 输出文件 | 文件路径 | 是 | 无 | 裁切结果输出路径 |
| 图层名 | 字符串 | 否 | 无 | 输入图层名 |
| 裁切矢量 | 文件路径 | 是 | 无 | 裁切边界数据，默认使用其第一个图层 |

## 算法内容

裁切前，程序会把裁切图层中的几何做标准化处理，必要时尝试自动修复非法几何。对于普通面面、面线、线线等情况，按相交关系计算交集；对于“线图层被面图层裁切”的情况，当前实现不是直接做一次整体交集，而是先按裁切面边界把线分段，再保留落在裁切面内的线段，以减少混合维度叠加时的异常结果。输出中只保留输入图层字段，不带裁切图层字段。

## 处理流程

1. 打开输入图层和裁切图层。
2. 检查两者是否使用相同坐标参考。
3. 读取裁切图层所有几何，并做标准化或自动修复。
4. 若裁切几何数量较少，预先合并为一个叠加几何；否则按要素局部构造候选叠加几何。
5. 创建输出图层并复制输入图层字段。
6. 逐条读取输入要素：
   - 线被面裁切时，先分段，再保留位于裁切范围内的线段；
   - 其它情况按相交关系计算交集几何。
7. 将非空结果写入输出图层。

## 结果解释

- 输出几何是输入要素被裁切后的部分
- 输出属性只来自输入图层
- 裁切边界本身不会写入结果
- 返回消息中的数量是成功写入的结果要素数
- 元数据键 `feature_count` 与返回消息里的数量同源（字符串形态），计的是写出的结果要素数而不是输入要素数；另带 `action` / `input` / `output` 三个标准回显键；裁切输入被逐条丢弃时另发 `clip_skipped_input_count`（>0 才出现，见“注意事项”）；其中"修复成功但维度降级（面修成线/点）"被丢的另发 `clip_degraded_input_count`（>0 才出现，自 N158 起，与 skipped 键互斥）

## 适用场景

- 用行政区边界裁切道路、水系、地块等矢量数据
- 从全国或全省数据中提取局部区域
- 用面范围裁切线状要素并保留有效线段
- 在专题分析前先统一分析范围

## 输出说明

- 输出图层保留输入图层字段结构
- 输出几何类型以输入图层有效类型为主
- 建议使用 `.gpkg` 保存结果，便于字段和几何稳定存储

## 推荐输出文件名

- `矢量裁切_result.gpkg`

## 注意事项

- 输入图层与裁切图层必须使用相同 CRS，否则实现会直接失败
- 裁切图层的输入几何**被逐条丢弃的有四类**：输入本身就是 NULL 几何、克隆失败、克隆出来就是 EMPTY、
  以及非法且自动修复（`MakeValid`）失败或修成 EMPTY —— **只有最后这一类进过修复**，前三类不走修复也照样被丢掉。
  丢弃不报错、不中断（自 N148 起逐条计入 `clip_skipped_input_count`，只在大于 0 时出现）；
  自 N158 起第五类：修复成功但维度低于输入（面修成线/点）同样被丢，计入 `clip_degraded_input_count`
  （与 skipped 键互斥）；N158 之前这类几何会以降级后的线/点无痕混进产物，现在产物只含与输入同维的结果。
  后果：这个键出现 ⇒ 该区域的裁切范围不再被扣掉 ⇒ 拿到的是**“少裁了一块”的成功产物**，动作**照样报 Success**、
  `feature_count` 照丢掉后的现实给（实测：裁切层 1 条有效面 + 1 条 NULL ⇒ `Success: Clip completed: 0 features clipped`
  同批里 `clip_skipped_input_count: 1`）；只有全部裁切几何都被跳过时才整条失败。
  核对：先查 `clip_skipped_input_count`，再比 `feature_count` 与预期，别指望这里报错。
- 当前实现只使用裁切文件的第一个图层；`图层` 参数只作用于输入图层，不影响裁切图层。
- **输出不能与 `输入文件` 或 `裁切矢量` 是同一个文件**（按路径等价判定，不是字符串比较：`dir\.\x.gpkg`、大小写不同的拼法都算同一个），否则在创建任何产物之前就失败（`Output must not be the same file as input: ...`）⇒ 想“原地裁切”做不到。

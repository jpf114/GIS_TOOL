## D1 为什么不是"改文档"就行

`output` 是**插件级** `paramSpecs()` 的必填项，而 vector 有 33 个动作，其中绝大多数确实要输出文件、
`info` 不要。现有机制里能表达"按动作收紧必填"的只有两处：

- GUI 侧：`ActionUiConfig.requiredKeys`（批次 B 已经在用，且 `vector.info` 已把 `output` 从面板去掉）；
- CLI/工作流侧：`validateActionSpecificParams()`（`src/framework/src/action_validation.cpp`，
  批次 A 建的按动作校验钩子）。

⇒ 正确修法是把 `output` 的插件级 `required` 放开为 `false`，改由 `action_validation` 对
**真正需要输出的动作**逐个要求非空。这会改变 CLI 的接受面（少一类假必填），属**参数契约变更**，
需要配套用例（哪些动作缺 `output` 仍要红、哪些动作不再要求）⇒ 列入批次 C，不在收尾轮顺手做。

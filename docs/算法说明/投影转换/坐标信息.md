# 投影转换 / 坐标信息

## 功能说明

读取输入栅格的尺寸、波段数、GeoTransform 和坐标系信息，并在结果面板中显示。

## 输入与输出

- 输入：栅格文件，常用 `.tif` `.tiff` `.img`
- 输出：无文件输出，仅返回文本结果和部分元数据

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入栅格路径。 |

## 算法内容

坐标信息不是一个数据改写算法，而是一个只读检查动作。当前实现打开输入栅格后，提取其尺寸、波段数、GeoTransform 和坐标系定义，并以文本和元数据形式返回，便于快速核对数据的空间参考状态。

## 处理流程

1. 打开输入栅格。
2. 读取栅格宽度、高度和波段数。
3. 读取 GeoTransform，提取原点、像元大小和旋转项。
4. 读取坐标系 WKT。
5. 如果能解析出坐标系权威编码，则附带 Authority 信息。
6. 以文本摘要和元数据形式返回结果，不生成输出文件。

## 返回内容

- 栅格宽高
- 波段数
- GeoTransform
- CRS WKT
- CRS Authority 信息

## 返回字段说明

- `width`：栅格宽度
- `height`：栅格高度
- `bands`：波段数量
- `wkt`：完整 CRS WKT 字符串

## 结果解释

- `Origin`、`Pixel Size`、`Rotation` 可用于检查栅格是否具有正常地理定位。
- `wkt` 和 Authority 信息可用于确认当前数据到底处于哪个坐标系。

## 适用场景

- 数据入库前检查。
- 重投影、裁切、配准前核对空间参考。

## 输出说明

- 本功能不生成输出文件。
- 结果以文本和元数据形式返回，适合用于快速核对坐标系、GeoTransform 和尺寸信息。

## 注意事项

- 当前实现按栅格方式读取，不适合拿来查看矢量数据详情。
- 返回文本中会显示 `Origin`、`Pixel Size`、`Rotation`，方便核对地理定位是否正常。

## 键与文本的分工（批次 D D1-P 实测对齐）

- 元数据里**只有** `width`、`height`、`bands`、`wkt` 四枚键；
  **没有** `pixel_size`、`origin`、`extent` 这类键 —— 原点、像元大小、旋转项与 Authority 只出现在文本结果里。
  ⇒ 需要在程序里核对像元尺寸或包框时，要么解析文本，要么改用 `raster_inspect / info`。
- 文本用默认输出流精度（6 位有效数字），因此较大的投影坐标会印成科学计数法：
  例如 `12935000` 印为 `1.2935e+07`、`4852300` 印为 `4.8523e+06`，而 `50`/`-50` 这类小值原样印出。
- 包框四边本动作**不输出，两侧也就都没有判据**（登记为缺口）：它只能由已输出的量推出
  `x_max = OriginX + width × PixelSizeX`、`y_min = OriginY + height × PixelSizeY`
  （例如 `116.0 + 20 × 0.001 = 116.020`、`40.0 + 10 × (-0.001) = 39.990`）——而"拿已经被判读的数算出来的式子"
  本身不构成判据：Origin 与 Pixel Size 那四支为绿时它的差恒等于 0。要核对包框请解析文本，
  或改用 `raster_inspect / info`（它的文本印 `Extent: (minX, minY) - (maxX, maxY)`）。
- 判据凭据（Debug）：`PluginTest.ProjectionInfoExecution` 判的是文本里三对读数各自的数 ——
  像元尺寸 `±0.001`、原点 `116.000`/`40.000`、旋转项 `0.0`/`0.0`（六枚的期望全部来自夹具 `adfGT` 字面量，
  不从产物回填），再加 `wkt` 读回的权威码恰为 `4326`。取证方式：把 Origin 两个数写反的产品变异臂已红（批次 D D1-P Step3）；
  旋转那一对则用两条反事实臂取证——把它的期望常数单独改错、以及只把输入栅格的旋转项写成非零（产品码一字未动），
  两条都只让旋转支单独红、Origin/Pixel Size 四支保持绿。腿侧 `projection_info` 另钉两枚由生成器字面量可推的读数
  （`Pixel Size: (50, -50)`、`Origin: (1.2935e+07, 4.8523e+06)`）。

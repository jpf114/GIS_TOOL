# 影像处理与分析 / 霍夫变换

## 功能说明

检测输入影像中的直线或圆形结构，并输出检测结果掩膜。

## 输入与输出

- 输入：栅格影像
- 输出：检测结果栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入影像。 |
| 输出文件 | 文件路径 | 是 | 无 | 输出检测结果。 |
| 波段号 | 整数 | 否 | `1` | 从 1 开始。 |
| Hough类型 | 枚举 | 否 | `lines` | `lines` 或 `circles`。 |
| Hough阈值 | 浮点数 | 否 | `50.0` | 累加器阈值。 |
| 最小线长 | 浮点数 | 否 | `50.0` | 直线检测使用。 |
| 最大线间距 | 浮点数 | 否 | `10.0` | 直线检测使用。 |
| 最小半径 | 整数 | 否 | `1` | 圆检测使用。 |
| 最大半径 | 整数 | 否 | `0` | 0 走「不设上界」的自动档；`circles` 支里它的现状后果见注意事项第 3 条（已知缺陷 N185，登记在 RELEASE 批次 D P5b 一节），本刀只说明、不改默认值。 |
| 圆检测参数2 | 浮点数 | 否 | `30.0` | 圆检测累加器阈值。 |

## 算法内容

霍夫变换用于检测图像中的规则几何结构，当前实现支持两种模式：直线检测和圆检测。两支共用一次前级 Canny，但**消费它的只有 `lines` 支**：

- `lines`（直线）：先把 8 位灰度图做一次 Canny 边缘提取（低/高阈值固定 50/150，不可配），再把这份边缘送入概率霍夫直线检测。
- `circles`（圆）：同样做了那次 Canny，但送入霍夫圆检测的是**那份 8 位灰度图本身**，产品自己的 Canny 结果在这一支被丢弃；
  `HoughCircles` 内部会另起一套边缘（对灰度图求 Sobel 梯度，再按硬编码的 `param1=100` 做一次 Canny）。

最后输出的是检测掩膜图：把检到的线段或圆画在黑底上（线宽 2，圆另画一个圆心实心点）。

## 处理流程

1. 读取输入影像指定波段。
2. 将波段转为 8 位灰度图。
3. 执行一次 Canny 边缘提取（低/高阈值固定 50/150）。
4. 如果是 `lines` 模式，则把第 3 步的边缘图送入概率霍夫直线检测，检出的线段按线宽 2 绘制到结果图。
5. 如果是 `circles` 模式，则把**第 2 步的 8 位灰度图**（不是第 3 步的边缘图）送入霍夫圆检测，
   检出的圆按线宽 2 画圆周、再在圆心画一个实心点。
6. 将结果图转为浮点栅格输出（画布按 255 除以 255 归一，所以只剩 `0.0` 与 `1.0` 两档），尺寸与输入波段相同。
7. 在元数据中记录检测类型（`hough_type`）和检测数量（`detect_count`）两键。

## 输出内容

- 元数据返回检测类型和检测数量。

## 枚举值说明

### 霍夫类型

- `lines`：检测直线
- `circles`：检测圆

## 输出说明

- 输出结果为栅格文件。
- 建议优先使用 `.tif` 保存，便于后续在 CLI、GUI 或 GIS 软件中继续处理。

## 结果解释

- 输出不是参数表，而是把检测到的线或圆绘制后的结果掩膜。
- `detect_count` 表示本次检测到的结构数量。

## 适用场景

- 线状结构识别、道路/边界辅助检测和圆形目标提取。

## 推荐输出文件名

- `霍夫变换_result.tif`

## 注意事项

- 建议先确认输入波段号、数据类型和 NoData 设置是否正确。
- 输出结果受输入影像质量和参数设置影响较大。
- 产物是单波段 Float32 掩膜，值域只有 `0.0` 与 `1.0` 两档，尺寸与输入波段相同。这与 `template_match` 的产物口径
  相反（那边的响应图不做 /255，尺寸是 `(W-w+1)×(H-h+1)`），拿两份产物互相对量时别按同一套口径读。
- `最小线长`/`Hough阈值`/`最大线间距` 只在 `lines` 支被消费，`圆检测参数2`/`最小半径`/`最大半径` 只在 `circles` 支被消费；
  另外一半虽然都会被读取，但改动它们不会改变产物（`边缘阈值不可配`是另一回事：那次 Canny 的 50/150 写死在代码里）。
- `circles` 支请**显式给正的 `最小半径`/`最大半径`** 窗口。`最大半径` 留默认 `0` 时，产品把它映射成一个极大上界，
  上游按这个上界去开半径估计要用的数组：实测在 120 宽 × 80 高、圆心 (30,30)、半径 20 的实心盘上，
  给 `最大半径=40` ⇒ `detect_count: 1`；留默认 ⇒ 进程报 `bad array new length` 且不落盘；
  只有把 `圆检测参数2` 抬到候选圆心一个都没有（实测 900）才走得到「成功且 `detect_count: 0`」。
  ⇒ 默认值这条现状是**已确诊缺陷**（N185，登记在 RELEASE 批次 D P5b 一节，留待拍板），不是推荐用法；
  给正数窗口是目前唯一能拿到检出结果的路径。
- `圆检测参数2` 默认 `30` 在那件硬边合成盘上实测 0 检出，降到 15 与 10 才检出 1 个。真实影像要调到多少由边缘质量决定，
  本条只是合成件上的实测，不构成推荐值。
- 画出来的环比几何真值偏大：同一件上真值半径 20 的盘，其非零像元相对圆心的半跨是 22（其中 1 像元是线宽 2 的外溢）。
  拿产物量尺寸时把这一像元算进去。

# 影像处理与分析 / 骨架提取

## 功能说明

对二值目标执行形态学骨架提取，输出表示目标中心线结构的单波段结果。

## 输入与输出
- 输入：栅格影像
- 输出：骨架提取结果栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入栅格影像 |
| 输出文件 | 文件路径 | 是 | 无 | 输出骨架提取结果 |
| 波段号 | 整数 | 否 | `1` | 参与计算的输入波段 |

## 算法内容

骨架提取用于把前景目标逐步细化为近似中心线结构。当前实现会先把输入影像二值化，再通过反复腐蚀、开运算和差分累积的方式提取骨架。

细化用的结构元是固定的 3×3 十字核，即只判断上下左右 4 个直接相邻像元，不含对角方向。这一点直接决定结果：换成 8 邻域方核会得到不同的骨架，因此本功能的输出不能与任意"形态学细化"互换。

## 处理流程

1. 读取输入影像指定波段。
2. 将波段转为 8 位灰度图。
3. 对灰度图执行 Otsu 二值化，得到前景掩膜。
4. 初始化空骨架图和工作图。
5. 反复对工作图做腐蚀。
6. 对腐蚀结果做膨胀，再与原工作图做差，提取本轮被剥离出的骨架部分。
7. 将本轮骨架部分累积到总骨架图中。
8. 当工作图全部腐蚀为空时结束循环。
9. 将最终骨架结果输出为单波段栅格。

## 输出说明

- 输出为单波段骨架结果栅格
- 输出像元只取两个值：`1` 表示该像元属于骨架，`0` 表示不属于；不是标签矩阵，也不是灰度图
- 输出的宽高与输入一致，不做重采样也不改投影
- 骨架是输入前景掩膜的**子集**：只会从前景里挑像元，不会在背景上生成新的前景点
- 更适合已经二值化或前景背景差异明显的输入

## 结果解释

- 输出保留的是前景目标的细化中心线结构。
- 已经只有 1~2 像元宽的前景（细线、窄带）本身就是骨架，这类区域输出与输入掩膜逐像元相同；3 像元及以上厚度才会被继续细化。
- 实心方块这类孤立即状会被逐轮剥角，得到的骨架是它的两条对角线，而不是中心的一小块。
- 整幅取值相同（无前景可分）时，二值化后没有前景像元，输出整幅为 `0`。
- 对噪声多或前景粘连严重的输入，骨架结果会明显受影响。

## 适用场景

- 中心线提取、细长结构分析和后续拓扑检查前处理。

## 推荐输出文件名
- `skeleton_result.tif`

## 注意事项

- 对灰度影像直接使用时，结果强依赖输入前景质量
- 一般建议先做阈值分割，再做骨架提取

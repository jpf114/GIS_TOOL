# 影像处理与分析 / 轮廓提取

## 功能说明

先对输入影像做 Otsu 二值化，再按最小面积筛选轮廓并输出结果栅格。
二值化的阈值**不是参数**：它由影像自身的 8 位直方图现算（类间方差最大的一档），界落在哪一档直接决定前景是谁；
最小面积的口径也不是像素数（见"算法内容"与"注意事项"）。

## 输入与输出

- 输入：栅格影像
- 输出：轮廓掩膜栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入影像。 |
| 输出文件 | 文件路径 | 是 | 无 | 输出结果。 |
| 波段号 | 整数 | 否 | `1` | 从 1 开始。 |
| 最小面积 | 浮点数 | 否 | `100.0` | 小于该面积的轮廓会被丢弃。 |

## 算法内容

轮廓提取用于从灰度影像中提取独立目标的外部区域轮廓。当前实现先对影像做 Otsu 二值化，再找出外部轮廓，并按最小面积筛掉太小的目标，最终输出一个填充后的轮廓掩膜图。

三处口径需要单独说明，它们都会改变结果而不会报错：

- **阈值由 Otsu 现算，且是一个真实存在的档值。** 实现按 8 位直方图的 256 个桶**升序**扫描，取类间方差
  `q1*q2*(mu1-mu2)^2` 最大的那个桶下标作为阈值；**并列时保留先遇到的（即最小的）下标**。随后二值化用的是
  `src > 阈值 ? 255 : 0` 这个**严格大于**的口径 ⇒ **阈值那一档自己被判给背景**。
  影像里只有两档时，任何落在两档之间的阈值都给同一张二值图，"跑了 Otsu"与"写了个常数阈值"在产物上不可分辨；
  三档以上且中间档的归属会换边时，两者才分得开。
- **面积是多边形面积，不是像素计数。** 轮廓点取自像元中心格点，面积按鞋带公式对顶点求和后取一半，
  所以一个宽 W、高 H 的实心矩形给的是 `(W-1)*(H-1)`，而不是 `W*H`。链码近似只压缩共线的中间点、
  只留每段直线的首尾，顶点数变少但**面积不变**。
- **只取外部轮廓，且输出是填充区域。** 内部空洞**不会**生成独立的轮廓参与筛选，
  被保留的轮廓是以 `FILLED` 方式填进结果图的 ⇒ 产物是**面**不是**线**，环状目标中间的洞也会被填成前景。

## 处理流程

1. 读取输入影像指定波段。
2. 将波段转为 8 位灰度图。
3. 对灰度图执行 Otsu 二值化，得到前景掩膜。
4. 在二值图上提取外部轮廓。
5. 逐个计算轮廓面积。
6. 只保留面积大于等于 `最小面积` 的轮廓（闭区间，等于也保留），并将其**填充**绘制到结果图中。
7. 将结果按 `255 -> 1` 归一化后以 `Float32` 写出（产物取值只有 `0` 与 `1`），并记录总轮廓数和保留轮廓数。

`总轮廓数` 只由二值图上的连通前景块决定，**不受 `最小面积` 影响**；`最小面积` 只改 `保留轮廓数` 与产物。

## 输出内容

- 元数据返回总轮廓数与保留轮廓数。

## 输出说明

- 输出结果为栅格文件。
- 建议优先使用 `.tif` 保存，便于后续在 CLI、GUI 或 GIS 软件中继续处理。

## 结果解释

- 输出是一个掩膜型结果图，不是矢量轮廓文件；数据类型是 `Float32`，取值只有 `0` 与 `1`。
- 值为前景的位置表示被保留的轮廓区域，其他位置为背景；**环状目标中间的洞也是前景**（洞不成独立轮廓）。
- `最小面积` 处在临界值时结果**整块翻转**：一条轮廓的 `(W-1)*(H-1)` 恰好等于参数时保留，参数再大 1 就整块消失
  （产物全零、`Mean` 由该块占比直接跳到 `0`），不会出现"半边保留"。

## 适用场景

- 独立目标区域提取、面积筛选和目标前景粗分割。

## 推荐输出文件名

- `轮廓提取_result.tif`

## 注意事项

- 建议先确认输入波段号、数据类型和 NoData 设置是否正确。
- 输出结果受输入影像质量和参数设置影响较大。
- **按面积筛之前先换算口径**：`最小面积` 比的是 `(W-1)*(H-1)` 那个多边形面积，不是像元个数。
  一个 20 列 × 12 行的实心矩形像元数是 240，而面积是 `19*11 = 209` ⇒ 同一个目标在 `最小面积=209` 时保留、
  在 `最小面积=210` 时整块丢弃；按 2×12 与 3×12 两条窄岛来说，面积分别是 `1*11 = 11` 与 `2*11 = 22`，
  默认 `100` 会把它们全部筛掉。用"多少个像元"去估这个参数会系统性偏大。
- **阈值不可指定**：本动作没有阈值参数，同一批影像换一批（直方图变了）界就可能换档；
  如果目标前景的归属不符合预期，应改输入影像的拉伸/分级，而不是去找一个不存在的阈值参数。

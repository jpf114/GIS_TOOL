# 影像处理与分析 / 空间滤波

## 功能说明

对影像执行平滑、形态学等空间滤波。

## 输入与输出

- 输入：栅格影像
- 输出：滤波结果栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入影像。 |
| 输出文件 | 文件路径 | 是 | 无 | 输出结果。 |
| 波段号 | 整数 | 否 | `1` | 从 1 开始。 |
| 滤波类型 | 枚举 | 否 | `gaussian` | `gaussian` `median` `bilateral` `morph_open` `morph_close` `morph_dilate` `morph_erode`。 |
| 核大小 | 整数 | 否 | `5` | 滤波核或结构元素边长，**合法取值是「不小于 3 的奇数」**（3、5、7…）。CLI、GUI 与工作流在派发前做 action 级校验，偶数或小于 3 直接返回「参数“核大小”必须是不小于 3 的奇数」而不进入算法；只有在进程内直接调用插件、绕过这层校验时，算法才会把偶数悄悄加一、把小于 3 的值抬到 3（不告警、不改返回状态），因此同一次调用的核尺寸可能与传入值不同。 |
| Sigma | 浮点数 | 否 | `1.5` | 标准差，**只有 `gaussian` 使用它**；`median`、`bilateral` 与四支形态学虽然都读这个键，但读后不参与任何计算（改它不改产物）。`gaussian` 的 σ 只改核的权重分布，不改核尺寸——尺寸始终取上面的「核大小」。 |

## 算法内容

空间滤波用于在局部邻域上平滑噪声、保留边缘或做形态学结构处理。当前实现支持高斯、中值、双边以及开闭运算、膨胀、腐蚀等多种方式，不同滤波器适合不同目标。

**七支分成两类量级，产物不可互相比较**：

- `gaussian` 在**输入的原始像元量级**上计算：读入即 `CV_32F`，全程不量化、不拉伸、不除 255，所以产物数值和输入同量级（输入是 0~51 时产物也在这个量级，可以远大于 1）。
- `median`、`bilateral` 与 `morph_open`/`morph_close`/`morph_dilate`/`morph_erode` 先按**该波段的 min/max 做全幅线性拉伸**转成 8 位，滤波后再除以 255 写回，所以这六支的产物恒在 `[0, 1]`。

## 处理流程

1. 读取输入影像指定波段（纯 RasterIO 读成 32 位浮点，不读 PAM/NoData 掩码）。
2. 进程内直调路径上对核大小做「偶数加一、小于 3 抬到 3」的静默修正；CLI、GUI 与工作流走的是派发前的 action 级校验，非法核大小会直接被拒（见参数表「核大小」的说明）。
3. 根据滤波类型进入不同处理分支。
4. `gaussian`：直接对浮点影像执行高斯平滑，不改变量级。
5. `median`、`bilateral`：先按该波段 min/max 全幅拉伸为 8 位灰度，再执行滤波，最后除以 255 转回浮点。
6. 形态学开闭、膨胀、腐蚀：先按该波段 min/max 全幅拉伸为 8 位灰度，构造矩形核后执行形态学处理，再除以 255 转回浮点。开、闭运算的默认边界值取 8 位域的另一端极值（腐蚀按 255、膨胀按 0），因此边界外的像元不会改变窗口内的最大/最小结果。
7. 将处理结果输出为单波段 32 位浮点栅格，尺寸等于输入该波段的宽高，地理参考与投影由输入透传。

## 输出说明

- 输出结果为栅格文件。
- 建议优先使用 `.tif` 保存，便于后续在 CLI、GUI 或 GIS 软件中继续处理。

## 结果解释

- 平滑型滤波更适合去噪。
- 形态学滤波更适合处理目标形状、孔洞和局部连接关系。
- 六支量化滤波的产物是**该波段内的相对位置**而不是原始像元值：量化标度取决于该波段的 min/max，
  同一算法在两个不同动态范围的影像上会得到不同的绝对读数，因此这些产物的像元值不可预期、也不可跨影像比较；
  需要保留原始量级时请用 `gaussian`（它不量化）。

## 适用场景

- 去噪、边界清理、形态优化和后续分割前处理。

## 推荐输出文件名

- `空间滤波_result.tif`

## 注意事项

- 结果按单波段栅格写出。
- 「核大小」必须是奇数且不小于 3；在命令行或界面里给偶数会被校验拦下，只有进程内直调会被静默改写。
- 「Sigma」只对 `gaussian` 有效；把它改成别的值不会改变另外六支的输出。
- 六支量化滤波的像元值依赖该波段的动态范围（全幅拉伸到 `[0, 1]`），跨影像比数值没有意义。
- 产物的文件字节不可比对（写出时带处理时间戳），要比就比波段数、宽高与像元统计量。

## 枚举值说明

### 滤波类型

- `gaussian`：高斯滤波
- `median`：中值滤波
- `bilateral`：双边滤波
- `morph_open`：开运算
- `morph_close`：闭运算
- `morph_dilate`：膨胀
- `morph_erode`：腐蚀

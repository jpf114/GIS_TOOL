# 影像处理与分析 / 阈值分割

## 功能说明

对指定波段执行阈值分割，输出分割结果栅格。

## 输入与输出

- 输入：栅格影像
- 输出：单波段结果栅格，建议 `.tif`

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 输入影像。 |
| 输出文件 | 文件路径 | 是 | 无 | 输出结果。 |
| 波段号 | 整数 | 否 | `1` | 从 1 开始。 |
| 方法 | 枚举 | 否 | `otsu` | `binary` `binary_inv` `truncate` `tozero` `otsu` `adaptive_gaussian` `adaptive_mean`。 |
| 阈值值 | 浮点数 | 否 | `128.0` | 普通阈值法（`binary` `binary_inv` `truncate` `tozero`）时使用；比较发生在归一后的 0..255 尺度上，不是原始像元值。 |
| 最大值 | 浮点数 | 否 | `255.0` | 阈值后赋值上限；产物里的高档是 最大值/255（默认即 1.0）。 |

## 算法内容

阈值分割用于把灰度影像按给定规则转成前景/背景或截断型结果。当前实现支持固定阈值、自适应阈值和 Otsu 自动阈值等多种方式，输出的是处理后的单波段结果图。

## 处理流程

1. 读取输入影像指定波段。
2. 将波段转为 8 位灰度图。
3. 根据所选方法进入不同阈值分支：
4. `otsu`：自动估计阈值并做二值化。
5. `adaptive_gaussian` / `adaptive_mean`：按局部邻域自适应计算阈值。
6. `binary`、`binary_inv`、`truncate`、`tozero`：按固定阈值和值域规则执行处理。
7. 将阈值结果转为浮点栅格输出。

## 输出说明
- 地理参考的口径（批次 D Task 8，2026-10-27）：源**取到**地理变换时原样带到产物；源**取不到**时产物就是**完全没有地理变换**
  （`gdalinfo` 读它不再出现 `Origin / Pixel Size` 那两行）。
- 改前不是这样：写出时不判取变换的返回值，于是把 GDAL 失败时填进数组的默认恒等式 (0,1,0,0,0,1) 当真实变换持久化进 GeoTIFF
  ⇒ 无参考输入会产出一张 `Origin = (0, 0) / Pixel Size = (1, 1)` 的图，看着像"有参考、分辨率是 1 单位"。
- **本动作的成败与产物在不在都不因这条改变**（既有契约：拿不到地理变换不得当成失败），改的只有产物里那一段元数据。

- 阈值语义与产物值域的四条口径（批次 D P1，2026-10-29；凭据见 `docs/RELEASE.md` 的
  「批次 D 覆盖晋升 P1」小节，判据块名 `PluginTest.ProcessingThresholdExecution`、真实腿 case 名
  `processing_threshold`）：
  - **阈值值比的是归一后的 0..255，不是原始像元值**。处理流程第 2 步先把波段归一到 8 位
    （min 落到 0、max 落到 255，标度是 `255/(max-min)`，取整是就近取整遇半取偶、不是截断），
    之后才比较。 ⇒ 对一张 float32 影像设 `阈值值=128` 不等于"原始值 128 以上算前景"。
  - **产物值域 = 最大值/255**。写出前统一乘 `1/255`，那个 255 是**写死的除数**、不是"最大值"，
    所以默认参数给出的是 0..1 的 Float32 单波段，不是 0/255 的 8 位图；要改产物上界改的是
    `最大值` 这一个参数。
  - **输入整幅同值时落进归一的退化分支**（`max - min` 小于 `1e-10` ⇒ 整幅置 0）：`binary` 的产物
    全 0，`binary_inv` 的产物全是 `最大值/255`。这是退化分支的形状，不是"阈值设错了"。
  - **`otsu` 不读阈值值**：OpenCV 在 `THRESH_OTSU` 下把阈值当**出参**，传与不传都由数据算；
    `adaptive_gaussian` / `adaptive_mean` 的 `blockSize=11`、`C=2` 写死在实现里，没有对外参数。
- 输出结果为栅格文件。
- 建议优先使用 `.tif` 保存，便于后续在 CLI、GUI 或 GIS 软件中继续处理。

## 结果解释

- 二值类方法更适合前景提取。
- 截断和置零类方法更适合值域裁剪和局部增强预处理。

## 适用场景

- 前景分割、掩膜生成和后续形态学/连通组件处理前准备。

## 推荐输出文件名

- `阈值分割_result.tif`

## 注意事项

- `otsu` 与自适应阈值会忽略固定阈值值。
- 这里有一处实现细节需要注意：
  - 执行层在外部完全不传 `method` 时，会回退到 `otsu`
  - 但 GUI 组合框当前会默认落到第一项，因此界面实际更接近默认 `binary`

## 枚举值说明

### 方法

- `binary`：大于阈值置为最大值
- `binary_inv`：反向二值化
- `truncate`：高于阈值截断到阈值
- `tozero`：低于阈值置零
- `otsu`：自动阈值
- `adaptive_gaussian`：自适应高斯阈值
- `adaptive_mean`：自适应均值阈值

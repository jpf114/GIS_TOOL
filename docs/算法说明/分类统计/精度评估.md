# 分类统计 / 精度评估

## 功能说明

把分类结果栅格与参考（地面真值）栅格逐像元对撞，生成混淆矩阵并派生总体精度、Kappa 系数、
各类的生产者精度与用户精度，结果写成一个 JSON 文件。

## 输入与输出

- 输入：分类结果栅格 + 参考栅格（两者像元行列数必须完全一致）
- 输出：精度评估结果 JSON（混淆矩阵、总体精度、Kappa、逐类 PA/UA、样本数）

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 分类结果栅格 | 文件路径 | 是 | 无 | 分类流程产出的类别栅格；缺失时报错 `classified_raster is required` |
| 参考栅格 | 文件路径 | 是 | 无 | 地面真值/参考类别栅格；缺失时报错 `reference_raster is required` |
| 输出文件 | 文件路径 | 是 | 无 | 结果 JSON 的路径；缺失时报错 `output is required` |

## 算法内容

混淆矩阵按 `confusionMatrix[参考值][分类值]` 构建：行是参考图上的一类，列是分类图上的一类，
格值是同时满足"参考为该列行、分类为该列"的像元数。因此三个指标的分母各不相同，
这是本动作在批次 A 的 Task 8 里纠正过的口径：

- **总体精度 OA** = 对角线之和 ÷ 有效像元总数。
- **生产者精度 PA**（producer's accuracy，即该类的召回率）= 该类对角格值 ÷ **该行之和**（参考图上属于该类的像元总数）。
- **用户精度 UA**（user's accuracy，即该类的精确率）= 该类对角格值 ÷ **该列之和**（分类图上判成该类的像元总数）。
- **Kappa** = `(OA - Pe) / (1 - Pe)`，其中 `Pe = Σ(行合计 × 列合计) / N²` 是"两图随机一致"的期望比例。

有效像元的判据：只有当栅格**真的声明了** NoData（`GetNoDataValue` 的成功标志为真）时，等于该值的
像元才被剔除；未声明 NoData 时返回值也是 `0.0`，若不看标志位就等于把"没声明"读成"0 是 NoData"，
会把合法的 0 类像元整类剔除出矩阵。任一图判为 NoData 的像元都跳过。

类集合取两图出现过的类的**并集**：只在一侧出现的类也会进表（另一侧全 0），
所以矩阵是 `class_count × class_count` 的满阵。

## 处理流程

1. 校验三个参数都非空，分别打开两幅栅格。
2. 比较两者行列数；不一致直接失败 `Raster dimensions do not match: classified WxH vs reference WxH`。
3. 读取两幅栅格**第 1 波段**的逐行数据（按 `GDT_Int32` 取）。
4. 逐像元跳过任一侧声明的 NoData，其余计入 `confusionMatrix[参考值][分类值]`，同时统计有效数与对角命中数。
5. 由矩阵算 OA、逐类 PA/UA 与 Kappa。
6. 把 JSON 写到输出路径（`overall_accuracy`/`kappa`/PA/UA 固定 6 位小数）。

## 输出说明

结果 JSON 的字段：

| 字段 | 含义 |
| --- | --- |
| `confusion_matrix` | 以参考类为键、每项内再以分类类为键的计数矩阵 |
| `class_names` | 参与统计的类值升序列表（就是栅格里的类值本身，不是名称） |
| `overall_accuracy` | 总体精度 |
| `kappa` | Kappa 系数 |
| `producers_accuracy` | 逐类生产者精度（分母＝参考图上该类像元数） |
| `users_accuracy` | 逐类用户精度（分母＝分类图上该类像元数） |
| `total_samples` | 有效像元数 |
| `correct_samples` | 对角命中像元数 |

运行元数据同时返回 `action=accuracy_assessment`、`overall_accuracy`、`kappa`、
`total_samples`、`correct_samples`、`class_count`。

## 结果解释

- PA 低说明该类**漏分**多（真值里是该类却没判出来）；UA 低说明该类**错分**多（判出来的多半是别的类）。
- Kappa 是相对"随机一致"的提升：接近 1 表示一致远超随机水平，接近 0 表示与随机猜差不多。
- `class_count` 明显大于预期时，检查是否参考图里存在分类图没有的类（或两侧各有背景值）。

## 适用场景

- 监督分类（SVM / 随机森林 / 最大似然）产出后的验收。
- 两期分类图互相核对（把较早一期当参考）。
- 图斑级精度汇报：把 JSON 里的矩阵直接接进报表。

## 推荐输出文件名

- `accuracy_assessment_result.json`

## 注意事项

- **只处理第 1 波段**：两幅图都取 `GetRasterBand(1)`，多余波段不参与统计。
- **不做几何对齐**：行列数不同直接失败；请先用投影/重采样工具把两幅图配成同网格同尺寸，
  本动作不做重投影也不做像元偏移补偿。
- **类值按 32 位整数读取**：若输入是浮点类别栅格，读取时会转成 `Int32`（小数部分被截断），
  请把类别编码写成整型栅格。
- 单类输入（两图都只有一个相同类）会让 Kappa 的分母 `1 - Pe` 为 0，代码没有为该退化输入特判 ⇒
  `kappa` 会按 IEEE 除法输出 `nan`。这种输入本身没有评价意义，但也不会被拦下来。
- 输出目录必须已存在：结果用普通文件流写，父目录缺失时报 `Cannot write output: <路径>`。
- 参考图本身要有可信的空间精度；参考与分类同源（例如都用同一影像自动提取）会系统性抬高各项指标。

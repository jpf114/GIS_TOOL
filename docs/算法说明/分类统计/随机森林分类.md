# 分类统计 / 随机森林分类

## 功能说明

使用训练样本 CSV 对多波段栅格执行随机森林监督分类。

## 输入与输出

- 输入：
  - 输入栅格：建议 `.tif`
  - 训练样本 CSV：至少包含一个标签列和若干特征列
- 输出：
  - 分类结果栅格：建议 `.tif`

## 训练样本 CSV 格式

```csv
label,b1,b2
1,10,20
1,12,18
2,200,180
2,195,185
```

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入文件 | 文件路径 | 是 | 无 | 待分类栅格 |
| 输出文件 | 文件路径 | 是 | 无 | 输出分类结果 |
| 训练样本 CSV | 文件路径 | 是 | 无 | 监督分类样本文件 |
| 标签列 | 字符串 | 否 | `label` | 类别标签列名 |
| 波段列表 | 字符串 | 否 | 空 | 逗号分隔，留空表示使用全部波段 |

## 算法内容

随机森林分类是一种基于多棵决策树集成投票的监督分类方法。它通过训练样本学习"不同类别在多波段特征空间中的分布差异"，再让每个像元经过森林中的多棵树独立判断，最终按综合投票结果给出类别。当前实现使用 OpenCV 的随机森林分类器，适合做轻量但相对稳健的栅格监督分类。

### 数学模型

**决策树分裂准则（基尼不纯度 Gini Impurity）**

对于节点上的样本集，设类别 c 的样本占比为 \(p_c\)，该节点的基尼不纯度定义为：

$$G = 1 - \sum_{c=1}^{C} p_c^2$$

其中 C 为类别总数。\(G\) 越小表示样本纯度越高（理想情况下单一类别时 \(G=0\)）。

对于候选分裂特征 f 及阈值 t，将样本集划分为左子集 \(S_L\) 和右子集 \(S_R\)，加权基尼不纯度为：

$$G_{\text{split}} = \frac{|S_L|}{N} G_L + \frac{|S_R|}{N} G_R$$

其中 \(N = |S_L| + |S_R|\)，\(G_L\) 和 \(G_R\) 分别为左右子集的基尼不纯度。算法选择使 \(G_{\text{split}}\) 最小的 (f, t) 作为当前节点的分裂准则。

**随机性来源**

1. **Bootstrap 采样**：每棵树从 N 个训练样本中有放回地抽取 N 个样本，约 36.8% 的样本不会被抽中（袋外样本 OOB）
2. **特征随机子集**：每棵树的每个节点分裂时，仅从 M 个总特征中随机选择 m 个特征作为候选（通常 \(m \approx \sqrt{M}\) 或 \(\log_2 M\)）

**集成投票**

对于 T 棵决策树，像元 x 的分类结果为：

$$y(x) = \arg\max_{c} \sum_{t=1}^{T} \mathbb{I}[h_t(x) = c]$$

其中 \(h_t(x)\) 为第 t 棵树的预测，\(\mathbb{I}[\cdot]\) 为指示函数。即选择获得最多树"投票"的类别。

**袋外误差估计（OOB Error）**

利用 Bootstrap 采样中未被抽中的袋外样本，可以对模型泛化能力进行无偏估计：

$$\text{OOB Error} = \frac{1}{N} \sum_{i=1}^{N} \mathbb{I}[y_{\text{OOB}}(x_i) \neq y_i]$$

其中 \(y_{\text{OOB}}(x_i)\) 仅使用那些未包含样本 i 的树进行投票。

### 关键参数含义

| 参数 | 符号 | 含义 |
|------|------|------|
| 树的数量 | T | 森林中决策树的个数，T 越大模型越稳定但计算量越大 |
| 最大深度 | D | 单棵树的最大深度，防止过拟合；0 表示不限制 |
| 特征子集大小 | m | 每节点分裂时随机选择特征的比例 |

与 SVM 类似，这里的训练样本输入是已经整理好的 CSV 特征表，而不是矢量样本图层。每一行训练数据都需要同时提供类别标签和对应波段特征值。

## 处理流程

1. 读取训练样本 CSV，识别标签列与特征列。
2. 解析全部训练记录，构造训练特征矩阵和类别标签。
3. 确定参与分类的波段列表；如果没有手动指定，则默认读取输入栅格全部波段。
4. 检查训练样本特征列数量是否与波段数量一致。
5. 用训练样本训练随机森林模型，建立类别判别规则。
6. 读取输入栅格中参与分类的各个波段。
7. 逐像元提取波段值，形成单个像元的特征向量。
8. 将该特征向量送入随机森林模型，得到预测类别。
9. 把预测类别写入单波段输出栅格，形成整幅分类结果。

## 输出说明

- 输出结果为单波段分类栅格
- 像元值即训练样本中的类别编号

## 结果解释

- 输出像元值就是模型预测的类别编号，编号来源于训练样本标签列。
- 随机森林对噪声样本和局部异常值通常比单一规则分类更稳一些，但结果仍然受训练样本代表性影响。
- 如果样本类别之间波段差异较弱，或者训练样本本身分布不均衡，结果仍可能出现混分。

## 适用场景

- 希望在现有样本表基础上快速得到监督分类图。
- 需要比单一线性判别更灵活的多波段分类方法。
- 做基础地物提取、样本验证和分类流程联调。

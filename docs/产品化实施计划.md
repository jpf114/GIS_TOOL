## 一、总体路线

### 1.1 核心原则

1. **先收口再扩展**：不盲目新增算法，先把已有成果稳住
2. **小步快跑**：每个阶段独立可交付、可测试、可验证
3. **复用现有架构**：在插件化 + 参数驱动体系上扩展，不大改框架
4. **按标准补全**：每个新能力都按"底层 → CLI → GUI → 参数校验 → 测试 → 文档"模板闭环

### 1.2 版本规划

| 阶段 | 目标版本 | 核心交付 | 复杂度 |
|------|----------|----------|--------|
| 阶段 A | v0.7.0 | 基础结果可视化 + 工程规范修复 + CI 改进 | 中 |
| 阶段 B | v0.8.0 | 元数据透传 + 分类精度评估 + 批量处理增强 | 中 |
| 阶段 C | v0.9.0 | 分块处理基础设施 + 工作流引擎 | 高 |
| 阶段 D | v1.0.0 | 生产级加固 + 日志增强 + 性能基准 + 用户引导 | 中 |

```yaml
env:
  VCPKG_DEFAULT_TRIPLET: x64-windows

steps:
  - name: Checkout
    uses: actions/checkout@v4

  - name: Setup vcpkg cache
    uses: actions/cache@v4
    with:
      path: |
        ${{ github.workspace }}/vcpkg
        ${{ github.workspace }}/vcpkg_installed
      key: vcpkg-windows-${{ hashFiles('vcpkg.json') }}
      restore-keys: |
        vcpkg-windows-

  - name: Install vcpkg and dependencies
    run: |
      if (-not (Test-Path vcpkg/vcpkg.exe)) {
        git clone https://github.com/microsoft/vcpkg.git
        cd vcpkg
        .\bootstrap-vcpkg.bat
      }
      .\vcpkg\vcpkg.exe install gdal opencv4 proj gtest qtbase --triplet x64-windows

  - name: Configure and Build
    run: |
      cmake -S . -B build/debug --preset debug
      cmake --build build/debug --config Debug
      cmake -S . -B build/release --preset release
      cmake --build build/release --config Release

  - name: Test Debug
    run: ctest --test-dir build/debug -C Debug --output-on-failure

  - name: Test Release
    run: ctest --test-dir build/release -C Release --output-on-failure

  - name: Package and Upload
    run: |
      cmake --install build/release --config Release
      Compress-Archive -Path install -DestinationPath gis-tool-win64.zip
    if: success()

  - name: Upload Artifact
    uses: actions/upload-artifact@v4
    with:
      name: gis-tool-win64
      path: gis-tool-win64.zip
    if: success()
```

**完成标准**：

### C1：分块处理基础设施

**目标**：支持超过内存的大影像分块读写处理，避免 OOM。

**设计**：

```cpp
class RasterBlockProcessor {
public:
    struct Block {
        int xOff, yOff, xSize, ySize;
    };

    struct Config {
        int blockSize = 256;           // 分块大小（像素）
        bool overlap = false;          // 是否重叠（滤波类算法需要）
        int overlapSize = 0;           // 重叠像素数
    };

    RasterBlockProcessor(const Config& config);

    using BlockFn = std::function<void(
        const Block& block,
        GDALRasterBand* srcBand,
        GDALRasterBand* dstBand,
        ProgressReporter& progress)>;

    void process(const std::string& inputPath,
                 const std::string& outputPath,
                 const BlockFn& fn,
                 ProgressReporter& progress);

    static std::vector<Block> computeBlocks(
        int width, int height, int blockSize,
        bool overlap = false, int overlapSize = 0);
};
```

### C2：工作流引擎

**目标**：支持多步骤算法编排，实现常用处理流程的一键执行。

**设计**：

```cpp
struct WorkflowStep {
    std::string pluginName;
    std::string actionKey;
    std::map<std::string, ParamValue> params;
    std::map<std::string, std::string> inputMapping;
};

class Workflow {
public:
    void addStep(const WorkflowStep& step);
    const std::vector<WorkflowStep>& steps() const;

    gis::framework::Result execute(ProgressReporter& progress);

    std::string name() const;
    void setName(const std::string& name);

private:
    std::vector<WorkflowStep> steps_;
    std::string name_;
};

class WorkflowManager {
public:
    static WorkflowManager& instance();

    void registerPreset(const std::string& name, const Workflow& workflow);
    const Workflow* findPreset(const std::string& name) const;
    std::vector<std::string> presetNames() const;

    bool saveToFile(const Workflow& workflow, const std::string& path);
    Workflow loadFromFile(const std::string& path);

private:
    std::map<std::string, Workflow> presets_;
};
```

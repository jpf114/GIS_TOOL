# GIS TOOL 用户手册

## 1. 简介

GIS TOOL 是一个面向 Windows 的 GIS / 遥感算法工作台，提供 GUI 和 CLI 两种使用方式，聚焦算法执行、结果产出、任务管理和回归验证，不包含地图展示平台能力。

当前主能力域包括：

- 投影转换
- 影像裁切与镶嵌
- 特征匹配与配准
- 影像处理与分析
- 分类统计
- 几何校正与辐射处理
- 地形分析
- 光谱指数
- 栅格工具
- 矢量数据处理

## 2. 安装与启动

### 2.1 环境要求

- Windows 10 或更高版本
- 项目安装产物或打包后的 Release 目录

### 2.2 安装方式

推荐使用 Windows 安装包；如果使用免安装目录，至少需要保留以下结构：

```text
install/
  bin/
    gis-cli.exe
    gis-gui.exe
  share/
    plugins/
    icons/
```

### 2.3 安装验证

```powershell
.\install\bin\gis-cli.exe --list
.\install\bin\gis-gui.exe -platform offscreen --self-test
```

## 3. GUI 使用指南

### 3.1 界面结构

GUI 主要分为三块：

- 左侧导航：按主功能域组织动作
- 执行页：参数填写、批处理、执行控制和结果摘要
- 任务中心：查看任务历史、日志和执行状态

### 3.2 基本操作流程

1. 在左侧选择主功能和子功能。
2. 在执行页填写输入、输出和高级参数。
3. 点击“执行处理”提交任务。
4. 在执行页或任务中心查看进度、日志和结果摘要。
5. 成功后可进入结果预览页查看部分结果。

### 3.3 首次运行

首次启动时会显示欢迎引导，帮助用户快速理解主功能域和基础操作流程。

### 3.4 参数填写

参数通常分为三类：

- 输入参数：输入文件、参考文件、波段、图层等
- 输出参数：输出路径、输出格式
- 高级参数：算法相关阈值、选项、模式

GUI 会尽量复用插件层的参数定义，因此参数名、说明和 CLI 语义应保持一致。

### 3.5 参数自动推导

系统会自动补一部分参数，减少重复输入：

- 根据输入路径推导默认输出路径
- 在自定义指数里根据预设补表达式
- 根据输入数据推导部分图层名或范围

### 3.6 批处理

执行页支持批处理模式：

1. 勾选批处理。
2. 选择输入目录。
3. 设置文件匹配条件。
4. 提交任务后，系统会为每个匹配文件创建独立任务并串行执行。

### 3.7 任务中心

任务中心可查看：

- 任务名称与状态
- 开始时间、结束时间、耗时
- 执行日志
- 重新执行、编辑参数、删除、清空等操作

### 3.8 任务取消

正在执行的任务可发起取消请求。取消会沿统一执行链向下传递，最终以结构化取消结果结束任务。

### 3.9 结果预览

执行成功后，部分结果可在 GUI 内直接预览：

- 栅格结果：缩略图、基础信息、部分统计
- 矢量结果：要素概览、部分属性预览
- 统计结果：JSON / CSV 的表格化或文本化展示

### 3.10 工作流

GUI 提供预设工作流入口，用于把多个动作串成一个处理流程。适合固定步骤较多的重复性任务。

### 3.11 日志与性能信息

系统会记录执行日志和部分耗时信息，便于：

- 回看失败原因
- 复核执行过程
- 比较不同参数或数据下的耗时表现

## 4. CLI 使用指南

### 4.1 查看可用插件

```powershell
.\install\bin\gis-cli.exe --list
```

### 4.2 查看帮助

```powershell
.\install\bin\gis-cli.exe projection --help
.\install\bin\gis-cli.exe projection reproject --help
```

### 4.3 执行算法

基本格式：

```powershell
.\install\bin\gis-cli.exe <plugin> <action> --input <path> --output <path>
```

示例：

```powershell
.\install\bin\gis-cli.exe spindex ndvi --input landsat8.tif --output ndvi.tif --red_band 4 --nir_band 5
.\install\bin\gis-cli.exe projection reproject --input image.tif --output reprojected.tif --dst_srs EPSG:3857
.\install\bin\gis-cli.exe terrain slope --input dem.tif --output slope.tif
.\install\bin\gis-cli.exe vector buffer --input roads.geojson --output buffer.geojson --distance 100
```

### 4.4 常见参数

| 参数 | 含义 |
| --- | --- |
| `--input` | 输入文件路径 |
| `--output` | 输出文件路径 |
| `--dst_srs` | 目标坐标系 |
| `--band` | 波段序号 |
| `--resample` | 重采样方式 |

## 5. 输出结果

常见输出格式：

- 栅格结果：`.tif`
- 矢量结果：`.geojson`、`.gpkg`、`.shp`
- 统计结果：`.json`、`.csv`

除主输出外，部分结果还会带有处理元数据，便于追溯插件、动作、参数和时间戳。

## 6. 常见问题

### 6.1 启动时提示找不到插件

检查：

- `share/plugins/` 是否存在对应插件文件
- 运行目录是否完整
- Release 安装产物是否拷贝完整

### 6.2 执行时报 `input is required`

这通常表示缺少必填输入参数。请检查：

- GUI 中是否已经选择输入文件
- CLI 中是否传入了 `--input`

### 6.3 输出为空或结果异常

优先检查：

- 输入数据是否满足算法前提
- 波段设置是否正确
- 参数是否超出合理范围
- 输出路径是否可写

### 6.4 光谱指数结果不合理

常见原因是波段映射错误。请确认传入的红光、近红外、短波红外波段号与实际数据一致。

常见参考：

| 数据源 | Blue | Green | Red | NIR | SWIR1 | SWIR2 |
| --- | --- | --- | --- | --- | --- | --- |
| Landsat 8/9 | 2 | 3 | 4 | 5 | 6 | 7 |
| Sentinel-2 | 2 | 3 | 4 | 8 | 11 | 12 |

## 7. 批量使用建议

### 7.1 GUI 批处理

如果是同一动作批量处理一组文件，优先使用 GUI 批处理模式，便于统一查看任务状态和失败日志。

### 7.2 命令行循环

Windows 下也可以通过脚本循环调用：

```batch
@echo off
for %%f in (*.tif) do (
    gis-cli spindex ndvi --input="%%f" --output="ndvi_%%~nf.tif"
)
```

### 7.3 发布前最小验收命令

```powershell
ctest --test-dir build/debug -C Debug --output-on-failure
ctest --test-dir build/release -C Release --output-on-failure
cmake --build build/release --config Release --target real_raster_regression
cmake --build build/release --config Release --target real_matching_regression
cmake --build build/release --config Release --target real_vector_regression
```

## 8. 注意事项

1. 重要数据建议先备份。
2. 大影像和大矢量任务建议预留足够磁盘空间。
3. 多源数据联合处理前，先确认坐标系一致。
4. 超大影像可优先考虑分块处理。
5. 遇到问题时优先保留输出日志和失败样例，便于复核。

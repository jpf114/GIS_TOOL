# GIS TOOL 用户手册

## 1. 简介

GIS TOOL（GIS 工具台）是一个跨平台的 GIS 算法工具集，提供 **10 大主功能、130+ 子功能**，覆盖从投影转换、影像处理、地形分析到矢量数据处理的完整 GIS 算法链路。支持命令行（CLI）和图形界面（GUI）两种使用方式。

## 2. 安装与启动

### 2.1 环境要求

- **操作系统**：Windows 10+ / Linux
- **运行时**：Visual C++ 运行时库（Windows）

### 2.2 安装

将 `install/` 目录复制到目标位置，目录结构如下：

```
install/
├── bin/
│   ├── gis-cli.exe        # 命令行入口
│   └── gis-gui.exe        # 图形界面入口
├── share/
│   ├── icons/             # SVG 图标资源
│   └── plugins/           # 算法插件 (.dll)
│       ├── plugin_projection.dll
│       ├── plugin_cutting.dll
│       └── ...
└── tools/
    └── gui_test_data_helper.exe
```

### 2.3 验证安装

```bash
# 命令行验证
gis-cli --list

# GUI 验证
gis-gui --self-test
```

### 3.2 基本操作流程

1. **选择主功能**：点击左侧导航栏中的主功能（如"地形分析"），下方展开该功能的所有子功能
2. **选择子功能**：点击子功能（如"坡度"），右侧面板显示功能说明和参数配置
3. **填写参数**：
   - **输入参数**（蓝色卡片）：输入文件、参考文件等
   - **输出参数**（蓝色卡片）：输出文件路径
   - **高级参数**（蓝色卡片）：算法相关的可调参数
4. **执行处理**：点击"执行处理"按钮，进度条显示处理进度
5. **查看结果**：执行成功后显示结果摘要

### 3.3 参数自动推导

系统会自动推导部分参数：

- **输出路径**：填写输入文件后，系统自动生成带合适后缀的输出路径
- **空间范围**：选择栅格输入后，系统自动读取其地理范围
- **图层名**：选择矢量输入后，系统自动检测第一个图层名
- **表达式**：在"自定义指数"中，选择预设表达式后自动填充公式

## 4. 命令行 (CLI) 使用指南

### 4.1 基本命令

```bash
# 查看所有可用插件
gis-cli --list

# 查看某插件的帮助信息
gis-cli projection --help

# 查看某插件某动作的详细参数
gis-cli projection reproject --help
```

### 4.2 执行算法

```bash
# 格式：gis-cli <插件名> <动作> --参数名=参数值

# 示例：NDVI 计算
gis-cli spindex ndvi --input=landsat8.tif --output=ndvi_result.tif --red_band=4 --nir_band=5

# 示例：重投影
gis-cli projection reproject --input=image.tif --output=reprojected.tif --dst_srs=EPSG:3857

# 示例：坡度计算
gis-cli terrain slope --input=dem.tif --output=slope.tif

# 示例：矢量缓冲区
gis-cli vector buffer --input=roads.geojson --output=buffer.geojson --distance=100
```

### 4.3 常用参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| `--input` | 输入文件路径 | `--input=data.tif` |
| `--output` | 输出文件路径 | `--output=result.tif` |
| `--dst_srs` | 目标坐标系 | `--dst_srs=EPSG:3857` |
| `--resample` | 重采样方式 | `--resample=bilinear` |
| `--band` | 波段序号（1 开始） | `--band=1` |

## 6. 常见问题

### 6.1 启动报错"未找到插件"

**原因**：插件目录未正确配置或缺失。

**解决**：
1. 确认 `share/plugins/` 目录下存在 `.dll` 文件
2. 确认 GDAL/PROJ 等运行时 DLL 在 PATH 中或与可执行文件同级

### 6.2 执行失败"input is required"

**原因**：未填写必填参数（输入文件）。

**解决**：在 GUI 中选中输入文件，或在 CLI 中加上 `--input=...`。

### 6.3 输出文件为空

**可能原因**：
- 输入文件波段数不足（如需要波段 5，但输入只有 3 个波段）
- 参数超出范围（如 `max_points` 设置过小）
- 输入数据格式不支持

**解决**：检查参数的取值范围是否匹配输入数据的实际属性。

### 6.4 光谱指数计算结果异常

**原因**：波段序号配置不匹配。

**常见卫星的波段序号**：

| 卫星 | 蓝 | 绿 | 红 | NIR | SWIR1 | SWIR2 |
|------|----|----|-----|-----|-------|-------|
| Landsat 8/9 | 2 | 3 | 4 | 5 | 6 | 7 |
| Sentinel-2 | 2 | 3 | 4 | 8 | 11 | 12 |

## 7. 批处理建议

### 7.1 Windows 批处理

```batch
@echo off
for %%f in (*.tif) do (
    gis-cli spindex ndvi --input="%%f" --output="ndvi_%%f"
)
```

### 7.2 Linux Shell

```bash
for f in *.tif; do
    ./gis-cli spindex ndvi --input="$f" --output="ndvi_$f"
done
```

## 8. 注意事项

1. **数据备份**：处理前建议备份原始数据，特别是使用格式转换功能时
2. **磁盘空间**：栅格处理可能产生较大临时文件，请确保磁盘空间充足
3. **坐标系一致性**：多源数据叠加分析时，请确保输入数据在相同坐标系下
4. **内存限制**：超大影像（>10GB）可能因内存不足而失败，建议先分块处理
5. **GDAL 驱动**：某些格式需要 GDAL 特定驱动支持，默认编译已包含常用驱动

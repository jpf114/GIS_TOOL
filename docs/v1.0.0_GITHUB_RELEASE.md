## GIS TOOL v1.0.0

Windows 插件式 GIS / 遥感算法工作台（CLI + GUI）。本版本聚焦**稳定、可验证、可交付**，不扩展地图展示或跨平台边界。

### 亮点

- 13 个算法插件，CLI / GUI 双入口
- GUI 任务中心、批处理、结果预览、预设工作流
- NSIS 安装包 + CI zip 产物
- 切片预览本地 Leaflet，无 CDN 依赖

### 安装

1. 下载 `gis-toolkit-1.0.0-win64-setup.exe` 并安装
2. 或解压 `gis-tool-win64.zip`，运行 `install/bin/gis-gui.exe`

详细说明见 [用户手册](docs/用户手册.md) 与 [v1.0.0发布说明](docs/v1.0.0发布说明.md)。

### 已知限制

- 仅 Windows x64
- `classification` / `georef` 为 0.1.0，能力可能不完善
- 无代码签名（SmartScreen 可能提示）
- `PerformanceMonitor` 未接入主执行链；GUI 任务中心日志仍为 SQLite 主路径

# GIS TOOL v1.0.0 变更摘要

## 1. 本轮目标

本轮工作的目标不是继续扩展产品边界，而是围绕 `v1.0.0` 收口当前工作区，完成以下几类事项：
- 补齐 GUI 主链相关页面与测试入口。
- 补齐 Windows 发布与安装交付能力。
- 修复构建、插件、GUI 与文档中的中文乱码问题。
- 将分析、实施计划、执行清单与发布说明整理为可追踪文档。
- 将提交历史按主题拆分，并统一中文提交信息。
- 将仓库依赖切换到仓库锁定的 `vcpkg manifest` 模式。

## 2. 主要变更

### 2.1 GUI 与测试
- 将结果预览页与工作流页面纳入 GUI 测试构建。
- 补充裁切、匹配、栅格工具等关键功能的 GUI 离屏回归测试。
- 收紧 GUI 执行链上的提示信息、状态文案与结果表达。

### 2.2 构建与发布
- 新增 Windows Release 的 NSIS 安装脚本与 `setup.exe` 产物。
- 将 Windows CI 调整为完整发布流水线：依赖安装、Debug/Release 构建、测试、安装、打包、产物上传。
- 在安装态产物上增加 smoke test，直接验证 `install/bin/gis-cli.exe` 与 `install/bin/gis-gui.exe`。
- 为 `vcpkg` 下载与配置步骤增加缓存与重试，降低网络抖动对 CI 的影响。

### 2.3 依赖与工程配置
- 为仓库补齐 `vcpkg.json` 的 `builtin-baseline`。
- 将 Qt 依赖明确为 `qtbase[sql,widgets]` 与 `qtsvg`。
- 在使用 `vcpkg` toolchain 时启用 manifest mode，避免依赖外部全局状态。

### 2.4 文档体系
- 补充《产品深度分析报告》《产品化实施计划》《基于当前现状的实施计划》《当前现状实施执行清单》。
- 更新《v1.0.0 发布说明》《v1.0.0 变更摘要》，使其与当前发布链一致。

## 3. 当前结果

当前仓库已经完成以下收口事项：
- 关键提交历史可读，且最近提交信息已统一为中文。
- Windows 发布链具备从源码到 zip/setup 安装包的自动化交付路径。
- 依赖版本由仓库内 manifest 锁定，不再依赖手工维护的全局安装状态。
- 发布说明与变更摘要已同步到当前仓库状态。

## 4. 当前仍遵守的边界

本轮整理不改变以下既定边界：
- 仅支持 Windows。
- 产品定位仍为插件式 GIS / 遥感算法工作台。
- 不引入地图展示平台能力。
- 不进行跨平台迁移与大规模架构重写。

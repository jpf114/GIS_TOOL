# GIS TOOL v1.0.0 变更摘要

## 1. 本轮目标

本轮工作的目标不是继续扩展产品边界，而是围绕 `v1.0.0` 收口当前工作区，完成以下几类事项：

- 补齐 GUI 主链相关页面与测试接入
- 补齐 Windows 发布与安装交付能力
- 修复构建、插件、GUI 与文档中的中文乱码
- 将分析、实施计划、执行清单与发布说明整理为可追踪文档
- 将提交历史按主题拆分并统一为中文提交信息

## 2. 主要变更

### 2.1 GUI 与测试

- 将结果预览页与工作流页面纳入 GUI 测试构建
- 补充裁切与匹配功能的 GUI 离屏回归测试
- 收紧 GUI 执行链上的提示信息、状态文案与结果表达

### 2.2 构建与发布

- 新增 Windows Release 的 NSIS 安装脚本
- 修复构建与发布链路中的中文提示信息
- 对齐 `README`、架构文档、用户手册与发布口径

### 2.3 文档体系

- 补充《产品深度分析报告》
- 补充《产品化实施计划》
- 补充《基于当前现状的实施计划》
- 补充《当前现状实施执行清单》
- 补充《v1.0.0 发布说明》

### 2.4 历史整理

- 将本轮相关提交按主题拆分
- 统一最近整理出的提交信息为中文
- 清理索引与工作树状态，确保仓库处于干净状态

## 3. 当前结果

当前仓库已完成以下状态收口：

- 提交历史按主题可读
- 提交信息统一为中文
- 工作树干净
- 发布说明与计划类文档已补齐

## 4. 当前仍需遵守的边界

本轮整理不改变以下既定边界：

- 仅支持 Windows
- 继续使用全局 `vcpkg`
- 产品定位仍为算法工作台
- 不引入地图展示平台能力
- 不进行跨平台迁移与大规模架构重写
